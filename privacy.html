MDStudio 개인정보 처리방침

시행일: 2026년 10월 1일
게시자: 풀빛컴퓨팅 (civilian7@gmail.com)

1. 요약

MDStudio는 사용자의 PC에서 동작하는 Markdown 편집기입니다. 게시자는 사용자의 문서나 개인정보를 수집하지 않으며, 게시자가 운영하는 서버로 전송되는 정보는 없습니다. 계정 가입이 없고, 사용 통계나 광고 식별자를 보내지 않습니다.

아래는 사용자가 직접 켜거나 실행했을 때만 PC 밖으로 정보가 나가는 기능과, PC 안에 저장되는 정보입니다.

2. 사용자가 실행했을 때 외부로 전송되는 정보

기능보내는 곳보내는 내용언제
AI 채팅·AI 편집사용자가 설정한 AI 제공자(Anthropic, OpenAI, Google 등) 또는 사용자가 지정한 주소사용자가 보낸 질문과, 사용자가 고른 문서 내용AI 기능을 사용할 때만. API 키는 사용자가 입력합니다
CLI 에이전트 모드사용자의 PC에 설치된 AI CLI(Claude Code, Codex, Gemini)위와 같음(전송은 해당 CLI가 합니다)에이전트 모드를 사용할 때만
웹 문서 가져오기, 웹 그림 내려받기사용자가 입력했거나 문서에 적힌 웹 주소해당 주소로의 요청그 명령을 실행할 때만
링크 검사 등 네트워크 권한이 있는 플러그인플러그인이 선언한 주소플러그인이 보내는 요청사용자가 플러그인 실행을 허용했을 때만

AI 제공자로 전송된 내용은 각 제공자의 개인정보 처리방침에 따라 처리됩니다.

3. PC 안에만 저장되는 정보

  • 설정·세션: 설정, 열었던 파일 목록, 창 배치. 사용자 폴더에 저장됩니다.
  • API 키·토큰: 운영체제의 자격 증명 저장소(Windows 자격 증명 관리자)에 저장됩니다.
  • 복구 사본: 저장하지 않은 문서의 사본을 암호화해 사용자 폴더에 둡니다. 정상 종료하면 지웁니다.
  • AI 대화 기록: AI 채팅을 쓰면 질문과 답이 사용자 PC에 기본 30일 동안 보관됩니다. 게시자 서버로 전송되지 않으며, 설정 > AI에서 저장을 끄거나 보관 기간을 바꿀 수 있습니다.
  • 로그: 오류 진단용 기록. 파일 경로가 포함될 수 있습니다. 기본 14일 뒤 지워지며 설정에서 끄거나 기간을 바꿀 수 있습니다.
  • 크래시 덤프: 프로그램이 비정상 종료했을 때의 진단 파일. 실행 중이던 메모리 일부(문서 조각 포함 가능)가 들어갈 수 있습니다. PC에만 보관되고 자동으로 전송되지 않으며, 최근 10개·30일까지만 보관합니다. 설정에서 끌 수 있습니다.
  • 사용자 정보(이름·소속·이메일): 사용자가 설정에 입력한 경우 문서 서식에 쓰입니다. AI 앱에 제공하는 기능은 기본으로 꺼져 있습니다.

4. 로컬 MCP 서버

사용자가 켠 경우에만, 같은 PC의 AI 앱이 문서에 접근할 수 있도록 로컬 주소(127.0.0.1)에서 서버가 동작합니다. 기본은 꺼져 있고 외부 네트워크에서는 접속할 수 없으며, 토큰으로 보호됩니다.

5. 제3자 제공·위탁

게시자는 사용자의 정보를 수집하지 않으므로 제3자에게 제공하거나 처리를 위탁하지 않습니다.

6. 아동

MDStudio는 아동을 대상으로 정보를 수집하지 않습니다.

7. 변경

이 방침이 바뀌면 이 페이지에 새 시행일과 함께 올립니다.
