자주 묻는 질문과 문의 방법입니다. 사용법은 사용 설명서에 있습니다.

자주 묻는 질문

어떤 Windows에서 쓸 수 있나요?

Windows 10 버전 1809 이상(64비트)입니다.

내 문서는 어디에 저장되나요?

사용자가 지정한 위치에 일반 .md 파일로 저장됩니다. 게시자는 문서를 수집하거나 게시자의 서버로 보내지 않습니다. 자세한 내용은 개인정보 처리방침을 확인하세요.

저장하지 않은 채 앱이 종료됐는데 글을 되살릴 수 있나요?

저장하지 않은 문서는 암호화한 복구 사본으로 사용자 폴더에 남아, 비정상 종료 뒤 다음에 실행할 때 되살릴 수 있습니다. 탭을 닫거나 앱을 정상적으로 종료하면 사본이 지워지므로 「저장 안 함」으로 닫은 문서는 되살릴 수 없습니다. 복구 사본은 중요한 문서의 백업을 대신하지 않으니, 자주 저장하세요.

AI 기능은 어떻게 쓰나요? 비용이 드나요?

AI 채팅과 편집은 사용자가 설정에서 제공자와 API 키를 직접 입력했을 때만 동작합니다. 키는 Windows 자격 증명 관리자에 저장됩니다. AI 제공자 쪽의 사용 요금은 사용자와 제공자 사이의 계약에 따르고, MDStudio는 요금을 받지 않습니다. 자세한 설정은 AI 설명서를 보세요.

다른 AI 앱(Claude Desktop 등)과 연결할 수 있나요?

MCP 서버를 켜면 같은 PC의 AI 앱이 열린 문서를 읽고 고칠 수 있습니다. 기본은 꺼져 있고, 이 PC 안에서만 토큰으로 연결됩니다. AI 에이전트 연결(MCP)을 참고하세요.

어떤 형식으로 내보낼 수 있나요?

PDF, HTML(파일 하나), Word(.docx), 블로그용 인라인 스타일 HTML, 순수 HTML, TextPack(.textpack)으로 내보냅니다. 설정에서 Pandoc을 켜면 odt·epub 같은 형식도 쓸 수 있습니다. 내보내기 설명서를 보세요.

단축키를 바꿀 수 있나요?

네. 단축키 바꾸기 설명서를 참고하세요. 모든 단축키는 앱 안 설명서(F1)의 「부록: 단축키」에 현재 키맵 그대로 나옵니다.

오류가 나거나 앱이 종료됐습니다.

오류 진단용 로그와, 비정상 종료 때의 진단 파일은 사용자 PC에만 보관되고 자동으로 전송되지 않습니다(진단 파일은 30일이 지나면 정리되고, 로그는 최근 파일만 남습니다). 문의할 때 상황(무엇을 하다가, 어떤 문구가 보였는지)을 적어 보내 주세요. 문서 내용이 담길 수 있으므로 파일은 요청드린 경우에만 보내세요.
