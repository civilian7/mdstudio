터미널

아래 도구 창의 터미널 탭에서 셸(PowerShell, cmd, Git Bash 등)을 바로 실행합니다. 다른 자리로 옮기거나 다른 탭과 묶을 수 있습니다.

열기와 닫기

  1. 보기 > 도구 창 > 터미널(Ctrl+`)을 클릭합니다.
  2. 처음 열면 터미널이 하나 자동으로 뜹니다.
  3. Ctrl+`를 다시 누르면 닫힙니다. 초점은 직전 자리(없으면 편집기)로 돌아갑니다.

새 터미널과 셸

  1. 보기 > 도구 창 > 새 터미널(Ctrl+Shift+`)을 클릭합니다.
  2. 도구 모음의 + 버튼은 설정한 셸로 새 터미널을 엽니다.
  3. ▾ 버튼을 누르면 「셸 선택」 목록이 나오고, 거기서 다른 셸을 고릅니다.
  4. 터미널 이름 옆의 ×(「닫기」)를 누르면 그 터미널이 닫힙니다. 돌고 있는 셸과 그 자식 프로세스도 함께 끝납니다.
  5. 셸이 끝나면 아래 줄에 종료 알림과 「다시 시작」 버튼이 나옵니다. 같은 설정으로 다시 시작합니다.

키

터미널에 초점이 있으면 키는 모두 셸로 갑니다. Ctrl+C 중단, Ctrl+D, Ctrl+Z, Tab, Esc, Alt+숫자도 셸이 받습니다. 앱으로 넘어오는 키는 아래뿐입니다.

키 동작
F1 도움말
Ctrl+Tab, Ctrl+Shift+Tab 문서 탭 이동
Ctrl+F4, Alt+F4 문서·창 닫기
Ctrl+` 터미널 열기·닫기
Ctrl+Shift+` 새 터미널
Ctrl+Shift+F 터미널 안에서 찾기. 터미널 밖에서는 파일에서 찾기

터미널 안에서 쓰는 키는 Ctrl+Shift+C 복사, Ctrl+Shift+V 붙여넣기, Ctrl+Shift+A 모두 선택입니다. Ctrl+Insert와 Shift+Insert도 같습니다. Shift+PageUp·Shift+PageDown은 스크롤백을, Shift+Home·Shift+End는 맨 위·맨 아래로 옮깁니다. 전체 화면 프로그램에서는 그 프로그램이 받습니다.

참고: Ctrl+C는 복사가 아니라 중단입니다. 복사는 Ctrl+Shift+C입니다.

찾기

  1. 터미널에서 Ctrl+Shift+F를 누릅니다. 선택한 글이 있으면 검색어로 들어갑니다.
  2. 검색어를 입력합니다. 스크롤백 전체에서 글자 그대로 찾아 강조합니다.
  3. Enter 또는 F3은 다음 일치, Shift+Enter 또는 Shift+F3은 이전 일치로 갑니다.
  4. Aa 버튼(「대소문자 구분」)을 누르면 대소문자를 구분합니다.
  5. Esc를 누르면 찾기 줄이 닫히고 초점이 터미널로 돌아갑니다.

찾기 줄에 초점이 있는 동안 입력한 키는 셸로 가지 않습니다.

마우스

  • 끌면 텍스트를 고릅니다. 더블클릭은 단어, 세 번 클릭은 줄, Alt를 누른 채 끌면 사각형입니다.
  • 휠은 스크롤백을 움직입니다. 오른쪽 스크롤 막대를 끌거나 막대 바깥을 클릭하면 한 화면씩 움직입니다.
  • vim, less처럼 마우스를 쓰는 프로그램 안에서는 클릭과 휠이 그 프로그램으로 갑니다. Shift를 누른 채 쓰면 다시 텍스트를 선택합니다.
  • 가운데 버튼은 붙여넣기입니다. 오른쪽 클릭 메뉴에는 「복사」, 「붙여넣기」, 「모두 선택」, 「스크롤백 지우기」가 있습니다.

붙여넣기

여러 줄을 붙여넣으면 줄마다 실행될 수 있으므로 「여러 줄을 붙여넣을까요?」 창이 먼저 뜹니다. [붙여넣기] 버튼을 누르면 붙여넣습니다. 줄 끝은 CR 하나로 바뀌고, 탭 외의 제어 문자(ESC 등)는 빠집니다.

설정

도구 > 설정 > 터미널에서 바꿉니다. 설정 파일에서는 [terminal] 항목입니다. 바꾼 값은 「새 터미널부터 적용됩니다.」

기본값은 설정의 기본값 표에서 봅니다.

설정 뜻
셸 auto(PowerShell 7, Windows PowerShell, cmd 순서로 찾음), pwsh, powershell, cmd, gitbash, 또는 실행 파일 경로
스크롤백 줄 수 500~100,000 줄
글꼴 크기 8~40. 0이면 편집기 글꼴 크기(확대·축소를 따름)
커서 깜빡임 커서를 깜빡일지 정합니다
여러 줄 붙여넣기 확인 끄면 여러 줄을 바로 붙여넣습니다
현재 문서가 있는 폴더에서 시작 끄면 홈 폴더에서 시작합니다
현재 문서 경로를 환경 변수로 전달 켜면 LUMI_DOC에 저장한 문서의 경로를 넣습니다. 다른 정보나 비밀은 넘기지 않습니다

저장하지 않은 문서면 탐색기의 첫 폴더, 그것도 없으면 홈 폴더입니다.

알아 둘 것

  • 셸에 글을 보내는 것은 사용자 입력뿐입니다. AI, 플러그인, MCP는 터미널에 글을 보낼 수 없습니다.
  • Windows 10 1809 이상이 필요합니다.
  • 한글 조합 중인 글은 밑줄로 보입니다.
  • PowerShell 5.1(powershell.exe)은 이모지를 내보내지 못합니다. PowerShell 7(pwsh)을 쓰세요.
