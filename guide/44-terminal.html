터미널

아래 도구 창의 터미널 탭에서 셸(PowerShell·cmd·bash …)을 바로 씁니다. SQLStudio 와 같은 내장 터미널입니다. 도구 창이라 다른 도크로 옮기거나 다른 탭과 묶을 수 있습니다.

  • 열기: 보기 > 도구 창 > 터미널 (Ctrl+` ), 새 터미널은 보기 > 도구 창 > 새 터미널 (Ctrl+Shift+` ). 처음 열면 터미널 하나가 자동으로 뜹니다.
  • 시작 폴더는 현재 문서가 있는 폴더입니다. 저장하지 않은 문서면 탐색기의 첫 폴더, 그것도 없으면 홈 폴더입니다.
  • 여러 터미널: 도구 모음의 + 가 새 터미널, 옆 ▾ 가 셸 선택입니다. 칩의 × 로 닫습니다(돌고 있는 셸과 그 자식 프로세스도 끝납니다).
  • 셸이 끝나면 아래 줄에 종료됨 · 코드 N과 다시 시작이 보입니다.

키

터미널에 초점이 있으면 키는 모두 셸로 갑니다(Ctrl+C 중단, Ctrl+D, Ctrl+Z, Tab, Esc, Alt+숫자 …). 앱 단축키는 가려지고, 아래 키만 앱으로 통과합니다.

키 동작
F1 도움말
Ctrl+Tab / Ctrl+Shift+Tab 문서 탭 이동
Ctrl+F4 / Alt+F4 문서·창 닫기
Ctrl+` 터미널 열기/닫기
Ctrl+Shift+` 새 터미널
Ctrl+Shift+F 터미널 안 찾기(터미널 밖에서는 파일 찾기)

터미널 안 전용 키: Ctrl+Shift+C 복사 · Ctrl+Shift+V 붙여넣기 · Ctrl+Shift+A 모두 선택(Ctrl+Insert/Shift+Insert도 됩니다) · Shift+PageUp/PageDown 스크롤백(전체 화면 프로그램 안에서는 프로그램에게 갑니다).

Ctrl+C는 복사가 아니라 중단입니다. 복사는 Ctrl+Shift+C.

찾기

Ctrl+Shift+F로 찾기 줄을 엽니다(선택한 텍스트가 있으면 미리 채움). 스크롤백까지 전체에서 글자 그대로 찾아 강조하고, Enter/F3 다음, Shift+Enter/Shift+F3 이전, Aa 대소문자 구분, Esc 닫기(초점은 터미널로)입니다. 찾기 줄에 있는 동안 키는 셸로 가지 않습니다.

마우스

끌면 텍스트를 선택합니다(더블 클릭 = 단어, 트리플 = 줄, Alt+끌기 = 사각형). 휠은 스크롤백을 움직이고, 오른쪽 스크롤 막대를 끌거나 막대 바깥을 클릭해 한 화면씩 움직입니다. vim·less 같은 프로그램이 마우스를 켜면 클릭·휠이 프로그램으로 가며, Shift를 누르면 다시 텍스트 선택입니다. 가운데 버튼은 붙여넣기, 오른쪽 클릭 메뉴에 복사·붙여넣기·모두 선택·스크롤백 지우기가 있습니다. 링크는 열지 않습니다.

붙여넣기

여러 줄은 줄마다 실행될 수 있어 먼저 묻습니다(설정에서 끌 수 있음). 줄 끝은 CR 하나로 바꾸고 ESC 등 제어 문자는 뺍니다.

설정

도구 > 설정 > 터미널 ([terminal])

설정 뜻
셸 auto(PowerShell 7 → Windows PowerShell → cmd), pwsh·powershell·cmd·gitbash, 또는 실행 파일 경로
스크롤백 줄 수 500~100,000 (기본 5,000)
글꼴 크기 8~40, 0 = 편집기 글꼴 크기(기본, 확대·축소를 따름)
커서 깜빡임 기본 켬
여러 줄 붙여넣기 확인 기본 켬
현재 문서가 있는 폴더에서 시작 기본 켬. 끄면 홈 폴더
현재 문서 경로를 환경 변수로 전달 기본 끔. 켜면 LUMI_DOC 에 현재 문서 경로(저장한 문서만)를 넣습니다. 다른 정보·비밀은 전달하지 않습니다.

새 터미널부터 적용됩니다. 글꼴은 편집기 글꼴(고정폭)을 따릅니다.

알아 둘 것

  • 입력은 사용자가 낸 것만 셸로 갑니다. AI·플러그인·MCP가 터미널에 텍스트를 보내는 길은 없습니다.
  • Windows 10 1809(빌드 17763) 이상이 필요합니다(ConPTY).
  • 한글 조합은 입력기 경로로 들어오며 조합 중 글은 밑줄로 보입니다. PowerShell 5.1(powershell.exe)은 이모지를 못 내보냅니다 — PowerShell 7(pwsh)을 쓰세요.
