탐색기

탐색기 도구 창에서 작업 폴더의 파일을 보고, 문서를 열고, 파일과 폴더를 만들고 정리합니다.

탐색기 열기

  1. 보기 > 도구 창 > 탐색기(Ctrl+Shift+E)를 클릭합니다.
  2. 왼쪽 도구 창에 탐색기가 열립니다.

트리는 구역 두 개입니다. 위쪽 구역에는 열어 둔 폴더(작업 폴더)가 고정되고, 「내 컴퓨터」 구역에는 드라이브가 나옵니다. 구역 머리 줄을 클릭하면 접힙니다.

작업 폴더 열기

  1. 파일 > 폴더 열기를 클릭합니다.
  2. 폴더 선택 대화상자에서 폴더를 선택합니다.
  3. 그 폴더가 위쪽 구역에 더해집니다.
  • 구역 머리의 + 는 「루트 폴더 선택」 창을 엽니다. 폴더를 선택하고 Enter 를 누릅니다.
  • 「내 컴퓨터」 구역의 폴더는 폴더 오른쪽 클릭 > 작업 폴더에 추가로 고정합니다.
  • 작업 폴더 줄의 「위로 이동」·「아래로 이동」은 순서를, 「루트 폴더 바꾸기」는 폴더를 바꿉니다.
  • 「작업 폴더에서 닫기」는 목록에서만 뺍니다. 디스크는 그대로입니다.

문서 열기

  1. 파일을 더블클릭하거나 선택하고 Enter 를 누릅니다.
  2. 문서가 탭으로 열립니다. 폴더는 한 번 클릭하면 펼치거나 접습니다.
  • 텍스트와 소스코드 파일도 열립니다. 열 수 없는 파일은 흐리게 보입니다.
  • 현재 문서를 바꾸면 탐색기가 그 파일을 펼쳐 선택합니다.
  • 이름 필터 칸에 글자를 입력하면 이름에 그 글자가 든 항목만 보입니다.

만들기와 이름 바꾸기

  1. 폴더를 오른쪽 클릭하고 「새 파일」 또는 「새 폴더」를 선택합니다.
  2. 트리 안의 입력란에 이름을 입력하고 Enter 를 누릅니다. 새 파일은 바로 열립니다.
  • 새 파일 이름에 확장자가 없으면 .md 가 붙습니다.
  • F2 나 「이름 바꾸기」로 이름을 바꿉니다. Esc 는 취소, 다른 곳 클릭은 확정입니다.
  • 이미 있거나 쓸 수 없는 이름이면 입력란이 남고 쓸 수 없는 까닭이 나옵니다.
  • 이름을 바꾸거나 옮기면 열린 탭이 새 경로를 따라갑니다.

복사·이동·삭제

  1. 항목을 선택하고 Ctrl+C(복사) 또는 Ctrl+X(잘라내기)를 누릅니다. Ctrl 이나 Shift 를 누르고 클릭하면 여러 항목을 선택합니다.
  2. 놓을 폴더를 선택하고 Ctrl+V 를 누릅니다. 같은 이름이 있으면 이름 (2) 로 만들어집니다.
  • 항목을 폴더 위로 끌어 놓으면 같은 작업 폴더 안에서 이동합니다.
  • Delete 키나 「휴지통으로」는 확인 창에서 **[휴지통으로]**를 눌러야 실행됩니다. 영구 삭제는 하지 않습니다.

문맥 메뉴

누른 자리에 맞는 항목만 나옵니다. 「숨김 파일 보이기」와 「탐색기 새로 고침」은 작업 폴더 줄 메뉴에 있고, 「탐색기 새로 고침」은 폴더 메뉴와 명령 팔레트(Ctrl+K)에도 있습니다.

  • 파일: 「열기」, 「링크로 등록」, 「잘라내기」, 「복사」, 「붙여넣기」, 「경로 복사」, 「상대 경로 복사」, 「파일 탐색기에서 보기」, 「이름 바꾸기」, 「휴지통으로」
  • 폴더: 파일 항목에 「새 파일」, 「새 폴더」, 「작업 폴더에 추가」 등이 더해집니다.
  • 작업 폴더 줄: 「새 파일」, 「새 폴더」, 「폴더 열기」, 「붙여넣기」, 「경로 복사」, 「숨김 파일 보이기」, 「작업 폴더에서 닫기」 등

링크로 등록

선택한 문서를 현재 문서의 links: 에 더합니다. 연결은 목차의 「연결된 문서」에 나옵니다.

  1. 저장한 문서를 열어 둡니다.
  2. 탐색기에서 마크다운 문서를 하나 이상 선택합니다.
  3. 파일 오른쪽 클릭 > 링크로 등록을 선택합니다.
  • links: 항목이 현재 문서 폴더 기준 상대 경로로 한 줄에 하나씩 더해지고, 새 문서는 맨 뒤에 붙습니다.
  • 이미 있는 연결과 문서 자신은 더하지 않습니다. 저장하지 않은 문서와 읽기 전용 문서에는 등록할 수 없습니다.
  • 편집 > 실행 취소로 한 단계씩 취소합니다.
