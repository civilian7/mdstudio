따라하기

따라하기는 한 가지 일을 처음부터 끝까지 손으로 해 보는 연습입니다. 편마다 5~10분 걸리고, 끝나면 결과 파일이 남습니다.

순서

모든 편이 같은 예제인 주간 보고 문서를 키워 갑니다. 앞 편을 하지 않았어도 각 편의 연습 파일로 바로 시작할 수 있습니다.

편 할 일 결과
새 문서를 만들어 저장하기 제목과 목록을 쓰고 저장하기 주간 보고.md
보고서 꾸미기: 표·그림·링크 표·그림·링크 넣기 표와 그림이 든 보고서
PDF·Word 로 내보내기 미리보기로 확인하고 내보내기 .pdf·.docx 파일
받은 한글·Word 문서를 가져와 고치기 가져오기, 찾기와 바꾸기 고친 .md 파일
매주 쓰는 보고를 템플릿으로 내 템플릿 만들기, 템플릿으로 새 문서 내 템플릿과 새 주간 보고
실수했을 때 되살리기 실행 취소·다시 실행 지운 내용을 되살린 보고

AI 앱과 함께

편 할 일 결과
Claude 로 MDStudio 조작하기 Claude Desktop·Claude Code 연결, 말로 부탁해 고치기 Claude 가 고친 보고, PDF, 견적서

이 편은 「AI와 확장」 부에 있습니다. Claude Desktop 이나 Claude Code 가 필요합니다.

연습 파일

  • 편 첫머리의 연습 파일 열기 링크를 클릭하면 시작 파일을 복사하고 첫 문서를 엽니다.
  • 복사하는 곳은 문서 폴더 아래 MDStudio 따라하기 폴더 안의 편 이름 폴더(예: MDStudio 따라하기\05-tut-report)입니다.
  • 이미 받은 연습 파일이 있으면 처음 상태로 다시 받을지 묻습니다. [예] 버튼은 다시 받고, [아니요] 버튼은 지금 있는 것을 그대로 엽니다.
  • 연습 파일 링크는 앱 안 설명서(F1)에서만 동작합니다.
