외부 프로그램

자주 쓰는 프로그램을 등록해 두고 도구 메뉴에서 바로 실행합니다. 지금 문서의 경로나 선택한 텍스트를 인자로 넘길 수 있고, 프로그램의 출력을 메시지 창이나 새 문서로 받을 수 있습니다.

프로그램 등록하기

  1. 도구 > 외부 프로그램 설정을 클릭합니다. 등록한 프로그램이 있으면 이 명령은 「외부 프로그램」 하위 메뉴 맨 아래에 있습니다.
  2. [추가] 버튼을 클릭합니다.
  3. 「프로그램」 칸 옆의 [찾아보기...] 버튼을 클릭해 실행 파일(.exe)을 선택합니다. 「이름」은 실행 파일 이름으로 채워지며 바꿀 수 있습니다.
  4. 「인자」에 프로그램에 넘길 값을 적습니다. [매크로] 버튼을 클릭하면 아래 표의 매크로를 끝에 넣습니다.
  5. 필요하면 「작업 폴더」·「출력」을 정하고 「실행 전에 현재 문서 저장」을 켭니다.
  6. [저장] 버튼을 클릭합니다. [취소] 버튼을 누르면 고친 내용을 버립니다.

목록의 [위로]·[아래로] 버튼으로 순서를 바꾸고, [삭제] 버튼으로 지웁니다. 20개까지 등록할 수 있습니다.

실행하기

  • 도구 메뉴의 「외부 프로그램」 하위 메뉴에서 프로그램 이름을 클릭합니다.
  • 명령 팔레트(Ctrl+K)에서 외부 프로그램: 다음에 이름을 입력해 찾습니다.
  • 단축키를 지정하려면 단축키 바꾸기에서 「외부 프로그램 1」~「외부 프로그램 20」 명령에 키를 지정합니다. 번호는 설정 창 목록의 순서입니다. 순서를 바꾸면 키는 그 번호 자리에 남습니다.

매크로

인자와 작업 폴더에 쓸 수 있습니다. 이름의 대소문자는 가리지 않습니다.

매크로 값
$(FilePath) 현재 문서의 전체 경로
$(FileDir) 현재 문서의 폴더
$(FileName) 현재 문서의 파일 이름
$(FileBase) 확장자를 뺀 파일 이름
$(SelText) 선택한 텍스트
$(Line) 커서 줄 번호
$(Column) 커서 칸 번호
$(WorkspaceDir) 탐색기 작업 폴더
  • 인자는 빈칸으로 나뉩니다. 빈칸이 든 값은 "…"로 묶습니다. 매크로 값은 빈칸이 있어도 인자 하나로 넘어갑니다.
  • 글자 $(를 그대로 넘기려면 $$(로 적습니다.
  • 파일 매크로는 저장한 문서에서만 쓸 수 있습니다. 모르는 매크로가 있으면 저장하지 않습니다.
  • 「작업 폴더」를 비우면 문서 폴더에서 실행합니다. 저장하지 않은 문서면 프로그램이 있는 폴더입니다.

출력 받기

출력 동작
받지 않음 프로그램을 띄우기만 합니다. 콘솔 프로그램은 자기 창을 엽니다.
메시지 창 아래 도구 창의 메시지 탭에 출력과 종료 코드를 적습니다.
새 문서 출력을 저장하지 않은 새 문서 탭으로 엽니다.
  • 출력은 1MB까지 받고, 120초가 지나면 프로그램을 끝냅니다. 도중에 멈추려면 「외부 프로그램」 하위 메뉴의 실행 중지를 클릭합니다.
  • 출력은 UTF-8로 읽고, 아니면 한국어 Windows 인코딩(CP949)으로 읽습니다.

안전하게 쓰기

  • 프로그램은 셸(명령 프롬프트)을 거치지 않고 실행합니다. 배치 파일(.bat, .cmd)이나 스크립트는 등록할 수 없습니다.
  • 명령 프롬프트·PowerShell 같은 셸이나 스크립트 실행기를 등록한 경우, 넘길 매크로 값에 &·|·"·% 같은 특수 문자가 있으면 실행하지 않습니다.
  • 값이 -로 시작하는 매크로가 인자 맨 앞에 오면 옵션으로 읽힐 수 있어 실행하지 않습니다.
  • 설정 파일을 직접 고쳐 넣은 항목은 처음 실행할 때 명령을 보여 주고 확인을 받습니다.
  • 네트워크 경로의 프로그램은 실행하지 않습니다.

참고: AI 채팅·MCP·플러그인은 외부 프로그램을 실행할 수 없습니다.
