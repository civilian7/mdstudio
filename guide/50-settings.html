설정

도구 > 설정...(Ctrl+Alt+S)은 [확인]을 클릭해야 반영되는 창입니다. 창이 열려 있는 동안 바꾼 값은 글꼴·편집기 모양처럼 화면에 바로 미리 보이지만, 파일에는 [확인]·Enter에서만 써집니다. [취소]·Esc·×는 연 때의 값으로 되돌립니다. 틀린 값은 빨간 글로 알리고, 그동안 [확인]은 창을 닫지 않습니다. 단, 다음은 클릭하는 즉시 실행되며 [취소]로 되돌릴 수 없습니다: AI 페이지에서 하는 일(제공자 추가·편집·삭제, API 키 저장·지우기, 연결 시험), MCP 토큰 새로 만들기, 파일 연결 [적용](이 묶음이 있는 판).

페이지 무엇
일반 사용자 정보(이름·소속·이메일 — 템플릿 토큰에 쓰임), 글꼴과 글꼴 크기, 시작
문서 저장(BOM, 줄 끝, 탭 폭, 자동 저장 간격, 외부에서 고쳤을 때), 그림(넣을 때 둘 폴더와 이름), 폴더(기본 문서 폴더, 최근 파일 개수), 파일 연결(Microsoft Store 판에는 없습니다 — 파일 형식을 이 프로그램으로 여는 연결은 Windows 가 맡습니다. Store 밖 배포판에서만: .md·.textpack·.txt·.json·.xml 을 이 프로그램으로 열기, .lumiplugin 을 두 번 클릭하면 플러그인 설치 확인)
편집기 표시(줄 번호, 접기 여백, 들여쓰기 안내선, 자동 줄 바꿈, 미니 도구 모음, 줄 간격·여백, 현재 줄 강조), 기능(린트, 실시간 미리보기), 자동 완성
단축키 모든 명령의 단축키 찾기·바꾸기(바로 저장, 단축키 바꾸기)
미리보기 미리보기 폭, 문서 속성 표시, 표 도구·스크롤·줄 바꿈, 편집기와 맞춰 스크롤
구문 색 편집기·코드 블록의 구문 색
AI 제공자·주소·모델·최대 토큰, API 키(키 저장소)
MCP 서버 켜기·포트·쓰기 도구 허용
시스템 프록시, 외부 도구(Pandoc 사용·경로), 이름 찾기 색인, 진단(로그, 크래시 덤프)
터미널 셸(목록에서 선택), 글꼴, 줄 수(터미널)

나머지 값은 **[설정 파일 열기]**로 config.toml 을 직접 고칩니다. 단축키 저장도 [취소]로 되돌릴 수 없습니다.

설정 파일 위치

파일 무엇
config.toml 설정
keymap.toml 바꾼 단축키
templates/·snippets/ 내 템플릿·스니펫(.hidden = 숨긴 기본 템플릿 목록)
plugins/ 플러그인

윈도우에서는 %APPDATA%\MDStudio 입니다.

  • 한영 변환: 자판 상태를 잘못 두고 친 글을 바꿉니다. 커서 바로 앞 단어(또는 선택한 텍스트)에서 도구 > 한영 변환(Ctrl+Alt+H)을 누르면 gksrmf 는 한글 로, ㅅ뮤ㅣㄷ 는 table 로 바뀝니다. 자동으로 바꾸지는 않습니다. Ctrl+Z 로 되돌립니다.
