설정

설정 창에서 글꼴·저장·편집기·미리보기 같은 앱 동작을 바꿉니다. 이 페이지의 기본값 표는 처음 설치했을 때의 값입니다.

설정 창 열기

  1. 도구 > 설정(Ctrl+Alt+S)을 클릭합니다. Ctrl+, 를 눌러도 됩니다.
  2. 왼쪽 목록에서 페이지를 선택합니다. 처음에는 「일반」이, 다음부터는 마지막으로 본 페이지가 열립니다.
  3. 값을 바꾸고 [확인] 버튼을 클릭합니다.
  • 페이지는 일반 · 문서 · 편집기 · 단축키 · 미리보기 · 구문 색 · AI · MCP · 시스템 · 터미널 순서입니다.
  • 창이 열린 동안 바꾼 값은 화면에 바로 보이고, 파일에는 [확인] 버튼이나 Enter 로만 저장됩니다.
  • [취소] 버튼이나 Esc 는 창을 열 때의 값으로 돌려놓습니다.
  • 틀린 값이 있으면 빨간 문구가 나오고 [확인] 버튼을 눌러도 창이 닫히지 않습니다.
  • 단축키 변경, API 키 저장, MCP 토큰 새로 만들기는 바로 적용되어 [취소] 버튼으로 취소되지 않습니다.
  • [설정 파일 열기] 버튼은 설정 파일 config.toml 을 엽니다.

설정 파일 위치

설정은 설정 폴더의 config.toml, 바꾼 단축키는 keymap.toml 에 저장됩니다. 폴더 경로는 도구 > 설정 > 문서의 「설정 폴더」에 나오고, [폴더 열기] 버튼으로 엽니다.

  • 같은 줄의 버튼으로 포터블(프로그램 옆 config 폴더)과 설치형(사용자별 설정 폴더)을 바꿉니다. 바뀐 자리는 다음 시작부터 씁니다.
  • 환경 변수 MDSTUDIO_CONFIG_DIR 에 폴더를 지정하면 그 폴더를 설정 폴더로 씁니다.

명령줄 시작 옵션

MDStudio.exe [옵션] [파일...] 꼴로 실행합니다. 옵션 앞에는 --·-·/ 를 붙일 수 있습니다.

옵션 동작
파일 경로 그 문서를 엽니다. 여러 개를 줄 수 있습니다
--clean 지난 탭과 복구 사본을 다시 열지 않고 시작합니다
--size 1280x800 창 크기(가로 x 세로, 각 320~8192)
--pos X,Y 창 위치. 음수도 됩니다
--monitor N 창을 둘 모니터 번호(1~16). --pos 가 없으면 그 모니터 가운데
  • --size=1280x800 처럼 = 로 써도 됩니다. 값이 틀리면 그 옵션만 무시합니다.
  • MDStudio 가 이미 실행 중이면 파일을 실행 중인 창에 넘깁니다.
