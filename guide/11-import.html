다른 형식 문서 열기

아래한글·Word·엑셀·PDF 문서와 웹 페이지를 마크다운 문서로 바꿔 엽니다. 원본 파일은 바뀌지 않습니다.

문서 파일 열기

  1. 파일 > 열기(Ctrl+O)를 클릭합니다.
  2. 열기 창에서 문서를 선택합니다. 여러 개를 한 번에 선택해도 됩니다.
  3. 열기 창의 열기 버튼을 클릭합니다.

원본과 같은 폴더에 마크다운 파일이 생기고 새 탭으로 열립니다. 형식은 확장자가 아니라 파일 내용으로 알아봅니다.

형식 확장자 옮겨지는 내용
아래한글 .hwp·.hwpx 본문, 개요 제목, 표, 그림
Word .docx 제목, 목록, 굵게·기울임, 링크, 표, 그림
엑셀 .xlsx·.xls·.ods 시트마다 시트 이름 제목과 표
PDF .pdf 본문, 제목, 괘선 표. 페이지 번호와 페이지마다 되풀이되는 머리·꼬리 줄은 뺍니다
  • 글꼴·글자 색처럼 마크다운에 없는 서식은 옮겨지지 않습니다. 바꾼 문서를 열어 원본과 비교합니다.
  • 스캔한 PDF 는 「이 PDF에는 텍스트 레이어가 없습니다」 알림이 나오고 열리지 않습니다.
  • 문서 파일을 창으로 끌어다 놓아도 같은 방법으로 바꿔 엽니다.

결과 파일 이름

  • 결과는 원본과 같은 폴더의 이름.md 입니다. 예: 보고서.docx → 보고서.md
  • 같은 이름의 .md 파일이나 이름.assets 폴더가 있으면 덮어쓰지 않고 이름 (2).md, 이름 (3).md 순으로 만듭니다.
  • 그림은 이름.assets 폴더에 풉니다.
  • 그 폴더에 쓸 수 없으면 저장 창이 열립니다. 저장할 위치와 이름을 정합니다. 저장 창을 취소하면 그 문서는 열지 않습니다.
  • 여러 문서를 한 번에 열면 하나씩 차례로 바꾸고, 끝나면 「마크다운으로 바꿔 열었습니다」 알림이 나옵니다.

암호 문서 열기

  1. 열기 암호가 걸린 아래한글·PDF 문서를 엽니다. 「암호 문서」 창이 열립니다.
  2. 「암호」 칸에 암호를 입력합니다.
  3. **[확인]**을 클릭합니다.

암호가 맞으면 문서를 바꿔 엽니다. 틀리면 「암호가 맞지 않습니다.」가 나오고 다시 묻습니다. **[취소]**를 클릭하면 열지 않습니다. 입력한 암호는 저장하지 않습니다.

  • 암호가 걸린 Word·엑셀 문서는 열지 못합니다. 원래 프로그램에서 암호를 푼 뒤 다시 엽니다.
  • 아래한글 배포용 문서는 열지 못합니다.

한도

  • 그림은 문서 하나에서 2,000개, 한 장에 100MB, 합계 1,024MB 까지 옮깁니다. 넘는 그림은 건너뛰고 나머지를 옮긴 뒤 건너뛴 수를 알려 줍니다.
  • 너무 큰 문서는 「문서가 너무 큽니다.」 알림이 나오고 열리지 않습니다.

Pandoc 으로 다른 형식 열기

설정 > 시스템 > 외부 도구에서 「Pandoc 사용」을 켜 두고 Pandoc 을 찾을 수 있으면 ODT·EPUB 같은 문서도 같은 방법으로 엽니다. 결과 파일 이름과 그림 폴더 규칙은 위와 같습니다. Pandoc 을 쓸 수 없을 때 이런 문서를 열면 「이 형식은 Pandoc으로 가져옵니다.」 알림이 나옵니다.

웹 페이지 열기

  1. 파일 > URL에서 열기(Ctrl+Alt+U)를 클릭합니다. 클립보드에 주소가 있으면 「주소」 칸에 미리 들어 있습니다.
  2. 「주소」 칸에 https:// 로 시작하는 주소를 입력합니다. 전에 연 주소는 칸 아래 목록에서 클릭해 넣을 수 있습니다.
  3. 그림까지 받으려면 「그림도 다운로드」를 선택합니다.
  4. **[확인]**을 클릭합니다.

웹 페이지의 본문만 추려 새 문서 탭에 엽니다. 「그림도 다운로드」를 선택했으면 문서를 먼저 저장하고 웹 그림을 문서 옆 폴더에 다운로드합니다.

  • 마크다운·텍스트 파일 주소는 내용을 그대로 엽니다.
  • 사설·내부 주소는 열지 않습니다. 응답이 8MB 를 넘거나 30초 안에 오지 않으면 열지 못합니다.
  • 본문을 찾지 못하면 「본문을 찾지 못했습니다.」 알림이 나오고 문서를 만들지 않습니다.

관련 페이지

  • 마크다운 문서를 열고 저장하는 법은 문서 열기와 저장을 봅니다.
  • 마크다운 문서를 다른 형식으로 저장하려면 내보내기를 봅니다.
  • 「Pandoc 사용」 같은 설정 항목은 설정을 봅니다.
