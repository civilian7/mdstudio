TextBundle·TextPack

TextBundle 은 본문과 그림을 한 덩어리로 주고받는 형식입니다. TextPack 은 같은 번들을 압축 파일 하나로 묶은 것입니다. 이 쪽에서는 번들을 열고, 저장하고, 내보내고, 보통 문서를 번들로 바꾸는 방법을 설명합니다.

열기

  1. 파일 > 열기를 클릭합니다.
  2. .textpack 파일을 선택하거나, .textbundle 폴더 안의 text.md를 선택합니다.
  3. 번들이 마크다운 문서 하나로 열립니다. 탭 이름은 이름.textpack 또는 이름.textbundle입니다.

참고: 탐색기에서 .textbundle 폴더는 폴더가 아니라 문서로 보입니다. 펼치지 않고 문서로 열 수 있습니다.

저장하기

번들 문서를 저장하면 고친 본문이 번들에 들어갑니다. 다른 앱이 쓴 항목과 그림은 그대로 둡니다.

  • .textbundle 폴더는 제자리에서 고치고, 그림은 그대로 둡니다.
  • .textpack은 열 때 임시 폴더에 풀고, 저장할 때 압축 파일 전체를 새로 만듭니다.
  • 번들에 쓰지 못하면 저장이 끝난 것으로 보지 않고 수정됨 표시를 남깁니다.
  • 탭을 닫으면 .textpack을 풀어 둔 임시 폴더를 지웁니다.

번들로 내보내기

  1. 파일 > 내보내기를 클릭합니다.
  2. 형식 목록에서 「TextPack 파일(.textpack)」을 선택합니다.
  3. 「폴더」와 「파일 이름」을 확인합니다.
  4. [내보내기] 버튼을 클릭합니다.

이렇게 보입니다: 저장 창 없이 바로 저장되고, 「내보냈습니다」 알림에 그림 장 수가 나옵니다.

내보낸 사본에서는 본문이 가리키는 로컬 그림을 assets 폴더로 복사하고 링크를 고칩니다. 웹 주소의 그림은 그대로 둡니다. 지금 문서는 바뀌지 않습니다.

참고: 열려 있는 문서와 같은 파일에는 내보낼 수 없습니다.

문서를 번들로 바꾸기

  1. 파일 > 다른 이름으로 저장을 클릭합니다.
  2. 파일 이름 끝에 .textbundle(폴더)이나 .textpack(압축 파일)을 붙여 입력합니다.
  3. 저장 창에서 저장합니다.

이렇게 보입니다: 탭 이름이 이름.textbundle로 바뀝니다. 그림은 번들의 assets 폴더로 복사되고 본문 링크도 assets/파일 이름으로 바뀝니다. 원래 파일과 그림은 그대로 남습니다.

팁: 명령 팔레트(Ctrl+K)에서 「TextBundle로 저장...」을 실행해도 됩니다. 이 명령은 메뉴에는 없습니다. 저장 창에서 이름만 적어도 .textbundle이 붙습니다.

번들 문서를 파일 > 다른 이름으로 저장에서 .md 이름으로 저장하면 그림을 이름.assets 폴더로 꺼내고 링크를 고칩니다. 이 뒤로 문서는 번들이 아닙니다.

그림 넣기

번들 문서에 붙여 넣은 그림은 번들의 assets 폴더에 들어갑니다. 그림을 찾을 때도 본문 옆의 assets 폴더를 기준으로 합니다. 그림을 넣는 자세한 방법은 삽입을 봅니다.

관련 페이지

  • 번들을 열고 저장하는 일반 방법은 문서 열기와 저장을 봅니다.
  • TextPack 을 포함한 다른 형식은 내보내기를 봅니다.
  • 그림 링크와 그림 넣기는 삽입을 봅니다.
