문맥 메뉴

오른쪽 클릭한 자리에 따라 나오는 메뉴를 모았습니다. 항목 이름은 메뉴에 보이는 그대로이고, —는 구분선입니다. 쓰는 법은 서식, 편집, 표, 삽입, 목차, 문제, 탐색기, 탭 페이지에 있습니다.

소스 편집기 본문

본문을 오른쪽 클릭하면 커서가 그 자리로 옮겨지고(선택한 텍스트 안은 선택 유지), 그 자리의 항목이 맨 위에 붙습니다. 해당하지 않는 항목은 흐리게 두지 않고 감춥니다. 자리가 겹치면 선택, 링크·그림, 표, 코드 블록, 줄 종류, 단어, 문제 순서로 쌓입니다.

누른 자리 맨 위에 붙는 항목
선택한 텍스트 굵게, 기울임, 인라인 코드, 링크 — 선택한 텍스트를 새 문서로... — 같은 단어 모두 선택, 선택한 줄마다 커서
링크 링크 따라가기, 링크 편집... — 주소 복사, 링크 해제(텍스트만 남김)
그림 그림 편집... — 그림 파일 열기, 경로 복사, 파일 탐색기에서 보기
표 표 편집... — 표 맞추기, 표 압축 — 행 아래에 넣기, 열 오른쪽에 넣기 — 표를 탭 구분 텍스트로 복사, HTML 표로 바꾸기...
코드 블록 코드 복사, 언어 바꾸기... (JSON·XML 글이면 JSON/XML 서식 정리, JSON/XML 한 줄로 줄이기도)
제목 줄 제목 수준 올리기, 제목 수준 내리기, 본문으로 바꾸기 — 이 절 선택, 이 절 접기, 이 절 복사 — 제목 번호 매기기...
목록 줄 완료로 표시 또는 미완료로 표시 — 한 단계 안으로, 한 단계 밖으로 — 글머리 기호 목록으로, 번호 목록으로, 할 일 목록으로
인용 줄 인용 풀기
보통 문단 줄 제목 1로, 제목 2로, 제목 3으로 — 글머리 기호 목록으로, 번호 목록으로, 할 일 목록으로 — 인용으로, 코드 블록으로
빈 줄 표 삽입..., 그림 삽입..., 링크 삽입..., 다이어그램 삽입
단어 이 단어 찾기, 같은 단어 모두 선택
고칠 수 있는 문제가 있는 줄 이 문제 수정
  • 지금 상태에 맞는 것만 나옵니다. 목록 줄에는 지금 종류로 바꾸는 항목이, 제목 1에는 「제목 수준 올리기」가 나오지 않습니다.
  • 마크다운이 아닌 문서에서는 선택과 단어 항목만 붙습니다.
  • 그 아래는 늘 같습니다: 실행 취소, 다시 실행 — 잘라내기, 복사 — 붙여넣기, 코드 블록으로 붙여넣기 — 삭제(선택했을 때) — 모두 선택 — 찾기 — 줄 복제, 줄 지우기.

그 밖의 자리

누른 자리 항목
줄 번호·북마크 칸 이 줄 북마크 설정/해제, 다음 북마크, 이전 북마크, 북마크 모두 지우기 — 이 줄로 이동, 이 줄 선택, 이 줄 복사, 이 줄 복제, 이 줄 지우기, 이 문제 수정(문제가 있는 줄만) — 줄 번호
접기 칸 이 구역 접기 또는 이 구역 펼치기 — 모두 접기, 모두 펼치기, 제목 수준까지 접기 — 접기 여백
미니맵 여기로 이동 — 맨 위로, 맨 아래로 — 미니맵
스크롤바 여기로 스크롤 — 맨 위로, 맨 아래로 — 한 페이지 위로, 한 페이지 아래로(세로). 가로는 맨 왼쪽으로, 맨 오른쪽으로
문서 탭 문서 닫기, 다른 탭 닫기, 오른쪽 탭 닫기, 저장한 탭 닫기, 모두 닫기 — 탭 고정 — 경로 복사, 파일 탐색기에서 보기 — 탭 그룹을 오른쪽에 나누기, 탭 그룹을 아래에 나누기
탐색기 파일 열기, 링크로 등록 — 잘라내기, 복사, 붙여넣기 — 경로 복사, 상대 경로 복사, 파일 탐색기에서 보기 — 이름 바꾸기..., 휴지통으로...
탐색기 폴더·작업 폴더 줄 새 파일..., 새 폴더...(도구 줄에는 없습니다)와 파일 항목. 작업 폴더 줄에는 폴더 열기..., 숨김 파일 보이기, 작업 폴더에서 닫기 등이 더해집니다
목차 항목, 문제 창 줄 목차는 제목, 그림, 표, 묶음 머리 줄마다 다릅니다. 문제 창에는 이동, 미리보기, 이 문제 수정, 빠른 수정..., 메시지 복사가 있습니다
미리보기 복사(선택했을 때만), 모두 선택 — 찾기, 다음 찾기·이전 찾기(찾은 곳이 있을 때만) — 내보내기...
  • 줄 번호 칸, 접기 칸, 미니맵, 스크롤바는 커서와 선택을 옮기지 않고 누른 줄이나 자리에 일합니다.

메뉴 막대에 없는 항목

  • 메뉴 막대에서 뺀 명령은 문맥 메뉴에서 씁니다. 선택한 텍스트를 새 문서로..., JSON/XML 서식 정리, 링크 따라가기, 표 편집·표 맞추기 같은 표 명령, 모두 접기·제목 수준까지 접기가 그렇습니다. 명령 팔레트(Ctrl+K)에도 있습니다.
  • 이 단어 찾기, 이 절 선택, 코드 복사, 링크 해제(텍스트만 남김), 주소 복사, 이 줄 복제처럼 누른 자리에서만 하는 항목은 문맥 메뉴에만 있고 명령 팔레트에도 없습니다.
