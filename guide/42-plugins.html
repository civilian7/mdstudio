플러그인 사용하기

플러그인은 문서를 읽고 고치는 작은 자바스크립트 확장입니다. 같은 정리를 한 번의 실행으로 되풀이합니다. 인터넷 접속 권한이 없는 플러그인은 문서를 밖으로 보내지 않습니다.

앱에 기본 플러그인 33개가 들어 있습니다. 직접 만들거나(플러그인 만들기) 받은 .lumiplugin 파일을 설치할 수도 있습니다.

플러그인 매니저 열기

활동 바의 플러그인 버튼을 클릭하거나 명령 팔레트(Ctrl+K)에서 「플러그인」을 실행합니다. 오른쪽 도구 창에 매니저가 열립니다.

  • 위 도구 줄: 찾기 칸과 아이콘 버튼(새 플러그인, AI로 만들기, 설치, 예제 문서, 내 플러그인 폴더 열기)이 있습니다.
  • 목록: 그룹별로 묶여 보입니다. 처음에는 기본 플러그인만 든 그룹이 접혀 있습니다. 줄이나 그룹을 오른쪽 클릭하면 이름 바꾸기, 그룹 옮기기, 모두 접기·모두 펼치기 메뉴가 나옵니다.
  • 가운데 도구 줄: 선택한 플러그인의 **[실행]**과 「코드 편집...」, 「복사본 만들기」, 「내보내기...」, 「폴더 열기」, 「삭제」 아이콘 버튼이 있습니다.
  • 아래: 설명, 할 수 있는 일, 접속할 곳, 실행하는 법, 최근 실행 결과가 보입니다.

실행하기

  1. 목록에서 플러그인을 선택합니다.
  2. **[실행]**을 클릭합니다. 현재 문서에 실행됩니다.
  • 명령 팔레트(Ctrl+K)에 플러그인: 을 입력해도 실행합니다.
  • 단축키는 설정의 단축키 쪽에서 「플러그인 슬롯 1」부터 「플러그인 슬롯 64」까지에 지정합니다. 칸 번호는 플러그인을 추가하거나 지워도 그 플러그인을 따라갑니다. 방법은 단축키 바꾸기를 참고합니다.
  • 필수 입력값이 있는 플러그인(예: 웹 문서 스크랩)은 실행 전에 입력 창이 뜹니다. 선택 입력값은 묻지 않고 기본값으로 실행합니다.
  • 한 번에 하나만 실행하며, 실행 중에는 **[중지]**로 멈춥니다.

결과 확인하기

결과 나오는 곳
문서를 고쳤다 문서에 바로 들어갑니다. 알림에 플러그인 이름과 요약이 나오고 [되돌리기] 버튼이 12초 동안 보입니다. 바꿀 곳이 없으면 「바꿀 곳이 없습니다」가 나옵니다
문제를 찾았다 아래 도구 창의 「점검 결과」 탭에 플러그인 이름으로 묶여 모입니다. 없으면 「문제가 없습니다」가 나옵니다
보고서·새 문서 새 탭(저장하지 않은 문서)으로 열립니다
  • 바뀐 문서마다 편집이 한 번이므로 Ctrl+Z 한 번으로도 실행 취소합니다. **[되돌리기]**는 그 뒤에 직접 고친 문서와 플러그인이 파일에 직접 쓴 내용은 되돌리지 않습니다.
  • 커서가 표 밖인 것처럼 지금 쓸 수 없는 상황은 오류가 아니라 안내 알림으로 나오고 문서는 그대로입니다.
  • 「메시지」 탭에는 실행 기록, console.log 텍스트, 오류가 쌓입니다.

권한과 실행 확인

할 수 있는 일은 매니저 아래에 배지로 보입니다. 경고 색 배지는 「문서 파일 열기」, 「문서 만들기·저장」, 「앱 명령 실행」, 「작업 폴더 파일 수정」, 「인터넷 접속」, 「비밀값 사용」, 「다른 플러그인 호출」, 「자동 실행(문서 저장·열기·닫기)」입니다. 그 밖의 「문서 읽기」, 「문서 수정」, 「앱 구성 읽기」, 「상태 표시줄」, 「설정 기억」, 「작업 폴더 파일 읽기」는 일반 색입니다.

직접 만들었거나 고친 플러그인과 설치한 플러그인은 처음 실행할 때 「플러그인 실행 확인」 창이 뜹니다.

  1. 폴더, 권한, 접속할 곳, 비밀값, 지문(파일 내용으로 만든 SHA-256 값의 앞 16자리)이 나옵니다. 처음 초점은 **[취소]**입니다.
  2. **[확인]**을 클릭하면 그 지문을 허용한 것으로 기억하고 실행합니다.
  3. 파일이 바뀌면 지문이 달라져 「파일이 허용한 뒤 바뀌었습니다」라고 다시 묻습니다.

앱과 함께 설치된 기본 플러그인과 새 플러그인 창으로 만든 플러그인은 묻지 않습니다. 이미 허용한 플러그인을 앱의 코드 탭에서 저장하면 허용이 이어집니다.

설치와 내보내기

받은 .lumiplugin 파일은 어느 길로 열어도 설치 확인 상자가 먼저 뜹니다.

  1. 위 도구 줄의 「플러그인 설치(.lumiplugin)...」 버튼, 명령 팔레트의 「플러그인 설치...」, 파일을 앱 창이나 매니저에 끌어다 놓기 중 하나로 엽니다. 연결해 둔 파일을 Windows 탐색기에서 두 번 클릭해도 됩니다.
  2. 이름, 버전, 만든 이, 할 수 있는 일, 접속할 곳을 읽습니다. 「자세히 보기」를 펼치면 코드 앞부분 80줄이 보입니다.
  3. **[설치]**를 클릭합니다. 같은 ID 가 있으면 버전을 견주어 보여 주고 버튼이 **[덮어쓰기]**가 됩니다.

자동 실행, 앱 명령, 파일 수정, 문서 만들기·저장, 모든 사이트 접속, 비밀값을 쓰는 플러그인은 **[취소]**가 기본 버튼입니다.

주의: 설치해도 믿어 주지 않습니다. 설치한 플러그인도 처음 실행할 때 실행 확인을 받습니다. 묶음의 지문은 파일이 깨지지 않았는지 보는 값이지 만든 사람의 서명이 아닙니다.

내보내려면 플러그인을 선택하고 「내보내기...」를 클릭한 뒤 저장 위치를 선택합니다. 기본 이름은 <ID>-<버전>.lumiplugin 이며 비밀값과 기억해 둔 값은 묶지 않습니다.

플러그인 관리하기

  • 「코드 편집...」은 코드 탭을 엽니다. 기본 플러그인은 내 플러그인 폴더에 사본을 만들어 그 사본을 고칩니다. 목록에는 사본만 보이고, 앱을 업데이트해도 고친 내용이 남습니다.
  • 「삭제」는 확인한 뒤 처리합니다. 기본 플러그인은 목록에서 숨기기만 하고, 목록 오른쪽 클릭 메뉴의 「숨긴 기본 플러그인 다시 보이기」로 되살립니다. 고친 사본은 사본만 휴지통으로 가고 원래 플러그인이 다시 보입니다. 직접 만든 플러그인은 휴지통으로 가며 비밀값과 기억해 둔 값도 지웁니다.
  • 켜고 끄는 스위치는 없습니다. 내 플러그인 폴더에 .js 파일이 있으면 목록에 나타납니다. 이 폴더는 기본으로 설정 폴더 안의 plugins 입니다(설정).

예제 문서로 시험하기

  1. 위 도구 줄의 「예제 문서(플러그인 시험용)」 버튼을 클릭합니다.
  2. 예제가 설정 폴더의 plugin-samples 폴더로 복사되고, 탐색기에 더해지며 README.md 가 열립니다.
  3. README 의 표에서 플러그인마다 열 문서와 기대 결과를 확인하고 실행해 봅니다.

문서는 일부러 어지럽혀 두었으니 마음껏 고쳐도 됩니다. 이미 복사한 예제가 있으면 묻습니다. **[예]**는 처음 상태로 다시 받고 **[아니요]**는 지금 있는 것을 그대로 엽니다.

자주 묻는 것

플러그인이 목록에 안 보입니다. 찾기 칸이 비어 있는지 보고 그룹 이름을 클릭해 펼칩니다. 숨긴 기본 플러그인은 목록 오른쪽 클릭 메뉴로 되살립니다.

설치했는데 실행하니 또 묻습니다. 정상입니다. 설치는 실행 허락을 주지 않으므로 권한과 지문을 보고 허락합니다.
