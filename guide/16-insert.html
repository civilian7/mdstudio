그림·링크·기호·다이어그램·수식

그림, 링크, 특수 기호, 다이어그램, 수식을 문서에 넣습니다. 표는 표를 봅니다.

그림 넣기

  1. 문서를 저장합니다. 저장하지 않은 문서는 「문서를 먼저 저장해야 그림을 넣을 폴더가 정해집니다.」 알림이 나오고 그림을 넣을 수 없습니다.
  2. 서식 > 그림을 클릭합니다. 「그림 넣기」 창이 열립니다.
  3. 창 위쪽의 폴더 아이콘(「그림 파일 열기」)을 클릭하고 그림 파일을 선택합니다.
  4. 「보여줄 텍스트」를 입력합니다. 비우면 파일 이름이 들어갑니다.
  5. **[확인]**을 클릭합니다.

그림 파일은 문서 옆 <문서 이름>.assets 폴더에 <문서 이름>_0001.png 처럼 번호를 붙여 복사됩니다. 커서 자리에는 ![텍스트](보고서.assets/보고서_0001.png) 가 들어갑니다.

  • 번호는 폴더의 가장 큰 번호 다음이고, 기존 파일은 덮어쓰지 않습니다.
  • 그림 위에서 끌어 영역을 선택하고 자르기 아이콘을 클릭하면 자릅니다. 너비·높이를 입력해 크기도 바꿉니다. SVG 는 자르거나 크기를 바꿀 수 없습니다.
  • 커서가 문서 옆 그림 위에 있으면 같은 창에 그 그림이 열립니다.

붙여넣기와 끌어 놓기

  • 클립보드에 그림만 있으면 Ctrl+V 로 같은 방식으로 들어갑니다. 텍스트가 함께 있으면(엑셀 셀 등) 텍스트가 붙습니다.
  • 파일 탐색기에서 그림 파일을 편집기로 끌어 놓아도 복사해 넣습니다. 여러 개면 한 줄에 하나씩 들어갑니다.
  • 한 번에 2,000장, 한 장 100MB, 합계 1GB 를 넘는 그림은 건너뛰고 「상한을 넘은 그림」 알림이 나옵니다.

웹 그림 내려받기

![](https://…) 처럼 웹 주소로 건 그림을 문서 옆 폴더로 내려받고 링크를 상대 경로로 바꿉니다.

  1. 문서를 저장합니다.
  2. 도구 > 웹 그림 다운로드를 클릭합니다.
  3. 알림에 저장한 그림 수가 나옵니다. 실행 취소(Ctrl+Z) 한 번에 원래 주소로 돌아옵니다.
  • 내려받지 못한 그림은 웹 주소 그대로 남습니다. 한 번에 100개, 한 장 20MB, 합계 200MB 를 넘는 그림은 건너뜁니다.
  • 도구 > 설정 > 문서의 「붙여넣은 텍스트의 웹 그림을 문서 옆에 다운로드」를 켜면, 붙여넣은 텍스트 속 웹 그림을 자동으로 내려받습니다.

링크 넣기

  1. 링크로 만들 텍스트를 선택합니다.
  2. 서식 > 링크를 클릭합니다. 「링크 삽입」 창이 열립니다.
  3. 「주소」에 https://… 또는 문서.md#제목 을 입력합니다. 「글자」와 「설명」은 필요하면 고칩니다.
  4. **[확인]**을 클릭합니다.

[글자](주소 "설명") 가 들어갑니다. 주소를 비우면 「주소를 적어 주세요.」가 나옵니다. 커서가 링크나 그림 위에 있으면 Ctrl+Enter 로도 그 링크·그림을 고치는 창이 열립니다.

링크를 오른쪽 클릭하면 「링크 따라가기」·「링크 편집」·「주소 복사」·「링크 해제(텍스트만 남김)」가, 그림을 오른쪽 클릭하면 「그림 편집」·「그림 파일 열기」·「경로 복사」·「파일 탐색기에서 보기」가 나옵니다.

깨진 링크 찾기

저장한 문서에서 가리키는 파일이나 그림이 문서 폴더에 없으면 깨진 링크입니다.

  • 문제 창과 편집기 밑줄에 「링크한 파일을 찾을 수 없습니다.」가 나옵니다(화면 구성). 문제를 오른쪽 클릭해 「이 문제 수정」을 선택하면 「링크 해제(텍스트만 남김)」 또는 「그림 제거」를 선택할 수 있습니다.
  • 한꺼번에 보려면 명령 팔레트(Ctrl+K)에서 「깨진 링크·그림 찾기」를 실행합니다. 방향키로 이동하고 Enter 를 누르면 그 줄로 갑니다.
  • 웹 주소, #제목 링크, 드라이브·네트워크 경로, 코드 블록 안은 검사하지 않습니다.

기호 넣기

  1. 서식 > 기호(Ctrl+.)를 클릭합니다. 「기호 삽입」 창이 열립니다.
  2. 왼쪽에서 「최근 쓴 것」·「전체」·종류를 선택하고, 격자에서 기호를 선택합니다.
  3. 더블클릭하거나 Space 를 눌러 「삽입할 기호」 칸에 모읍니다.
  4. **[확인]**을 클릭합니다.

모은 기호가 없으면 선택한 기호 하나를 넣습니다.

다이어그램 그리기

서식 > 다이어그램은 커서 자리에 순서도 예제가 든 코드 블록을 넣습니다. 예제를 고쳐 씁니다.

```mermaid
flowchart TD
    A[시작] --> B[처리]
    B --> C[끝]
```
  • 코드 블록 언어가 mermaid 면 mermaid, dot·graphviz 면 Graphviz 로 그립니다.
  • 미리보기에서 다이어그램에 마우스를 올리면 「그림으로 복사」 아이콘이 나옵니다.
  • 실시간 미리보기에서는 그림을 더블클릭하면 코드를 편집하고, 커서가 블록을 나가면 다시 그림이 됩니다.
  • 그릴 수 없는 코드는 그림 대신 원문 그대로 보입니다.

수식 쓰기

수식을 넣는 메뉴는 없습니다. LaTeX 로 직접 입력합니다.

  • 문장 안: $a^2+b^2=c^2$
  • 블록: $$ 줄 사이에 쓰거나 ```math 코드 블록에 씁니다.
  • $ 바로 뒤나 닫는 $ 바로 앞이 공백이거나 닫는 $ 바로 뒤가 숫자면 수식이 아닙니다. $5 그리고 $10 같은 금액은 그대로 둡니다.

관련 페이지

  • 표 삽입과 편집은 표를 봅니다.
  • 마크다운 문법은 마크다운 문법 요약을 봅니다.
  • 그림이 든 문서를 주고받는 방법은 TextBundle·TextPack을 봅니다.
