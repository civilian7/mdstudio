삽입

표

  • 서식 > 표...: 격자에서 행×열을 선택합니다.
  • 표 편집(Ctrl+Shift+T, 또는 표 안에서 Ctrl+Enter): 커서가 있는 표를 그리드에서 고칩니다. 첫 행이 머리글이고, 열 제목(A, B, …) 옆에 정렬(:--·:-:·--:)이 보입니다.

표 편집 창

동작 방법
셀 편집 글자를 치거나(한글도 바로) F2 · 더블클릭. Enter = 확정 후 이동(도구 모음 Enter 에서 제자리·오른쪽 셀·아래 행), Tab = 오른쪽 셀, Esc = 셀 편집 취소, Shift+Enter = 셀 안 줄바꿈(<br>)
행 추가·삭제 도구 모음·오른쪽 클릭 메뉴, Alt+Insert(아래에 행 추가), Ctrl+Y(행 삭제). 머리글 행은 삭제할 수 없습니다
열 추가·삭제 도구 모음·오른쪽 클릭 메뉴, Alt+Shift+Insert(오른쪽에 열 추가), Ctrl+Shift+Y(열 삭제). 마지막 한 열은 남습니다
행·열 옮기기 Ctrl+Alt+↑/↓(행), Ctrl+Alt+←/→(열)
정렬 왼쪽·가운데·오른쪽 정렬·정렬 해제(선택한 열 모두)
복사·붙여넣기 Ctrl+C = 선택한 범위를 탭 구분 텍스트로(Excel 에 붙여넣기). Ctrl+V = Excel·TSV·CSV 범위를 선택한 셀부터 덮어쓰고 모자라면 행·열을 늘립니다
내용 지우기 Delete
실행 취소 Ctrl+Z / Ctrl+Shift+Z(창 안)
  • [확인]은 표를 한 번에 되씁니다(문서에서 Ctrl+Z 한 번). 고친 것이 없으면 문서를 건드리지 않습니다. 고친 뒤 Esc·[취소]는 버릴지 묻습니다.
  • 셀 안의 | 는 \| 로, 줄바꿈은 <br> 로 적습니다.
  • HTML 표로 바꾸기(왼쪽 아래)는 열 폭을 정할 수 있는 HTML 표로 바꿉니다(되돌아오지 않음).
  • 커서가 HTML 표(<table>) 안이면 같은 창이 HTML 표를 엽니다. 범위를 선택하고 셀 병합, 병합 해제, 첫 줄 머리글, 커서 열의 폭을 고칠 수 있습니다. 병합된 셀에 덮인 자리는 고칠 수 없고, 병합이 있으면 행·열을 옮기거나 마크다운 표로 바꿀 수 없습니다. 셀에는 HTML 원문이 보이며 붙여넣은 텍스트는 이스케이프합니다.
  • 소스 편집기 문맥 메뉴: 표 맞추기·표 압축, 표를 탭 구분 텍스트로 복사.
  • 코드 블록 안 상자 그림(┌─┐)은 박스 표 맞추기(Ctrl+Shift+B)로 선을 다시 맞춥니다.

그림

  • 서식 > 그림...: 그림 파일을 선택하면 <문서>.assets/ 폴더로 복사하고 링크를 넣습니다. 커서가 그림 위면 대체 텍스트·주소·제목을 고칩니다. 저장하지 않은 문서에는 넣을 수 없습니다.
  • 클립보드에 그림만 있으면 Ctrl+V 로 같은 길로 들어갑니다.

링크·기호·다이어그램

  • 서식 > 링크...: 커서의 [텍스트](주소 "제목") 을 세 입력란에서 고칩니다. 깨진 링크와 그림은 문제 창(MD057)에 나오고, 명령 팔레트(Ctrl+K)의 깨진 링크·그림 찾기로도 봅니다.
  • 서식 > 기호...(Ctrl+.): 기호 673자를 종류별로, 최근 쓴 것이 앞에 옵니다.
  • 서식 > 다이어그램: 순서도 예제가 든 ```mermaid 코드 블록을 넣습니다. 다른 종류는 블록 첫 줄을 바꿉니다 — sequenceDiagram(시퀀스), classDiagram(클래스), stateDiagram-v2(상태). 실시간 미리보기에서는 그림만 보이고, 그림을 두 번 클릭하면 코드를 편집합니다.
