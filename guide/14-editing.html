편집과 이동

찾기·바꾸기

찾기 Ctrl+F, 바꾸기 Ctrl+H, 다음·이전 찾기 F3 / Shift+F3. 여러 파일에서 찾기는 탐색기·찾기.

이동

명령 단축키
줄로 이동 Ctrl+G
마지막 편집 위치로 Ctrl+Shift+Q
다음 / 이전 제목 Alt+PageDown / Alt+PageUp
문서로 이동(열린·최근 문서 선택) Ctrl+T

북마크

  • 북마크 설정/해제 Ctrl+F2 — 비어 있는 가장 작은 번호(1~9)를 씁니다.
  • 다음 / 이전 북마크 F2 / Shift+F2, 번호로 이동 Ctrl+1~9, 번호 지정 Ctrl+Shift+1~9.
  • 줄 번호 왼쪽 북마크 칸을 클릭해도 켜고 끕니다. 북마크는 이번 실행 동안만 남습니다.

접기

접기 여백(줄 번호 옆)을 오른쪽 클릭하면 이 구역 접기·펼치기, 모두 접기·펼치기, 제목 수준까지 접기 ▸ 가 나옵니다. 키는 접기·펼치기 Ctrl+Alt+← / → 이고, 나머지는 명령 팔레트(Ctrl+K)에도 있습니다. 접기 여백은 도구 > 설정... > 편집기에서 끌 수 있습니다.

줄 편집

편집 메뉴에 줄 복제·줄 지우기·줄 위로·아래로 옮기기·들여쓰기·내어쓰기·줄 주석이 있고, 나머지는 단축키와 명령 팔레트(Ctrl+K)로 씁니다: 줄 지우기(Ctrl+Shift+K), 줄 끝까지 지우기(Ctrl+Shift+Y), 위에 새 줄, 줄 위로 옮기기·줄 아래로 옮기기(Alt+↑ / ↓), 들여쓰기·내어쓰기(Ctrl+] / Ctrl+[), 줄 주석 켜기/끄기(Ctrl+/). 들여쓰기·내어쓰기와 Tab·Shift+Tab 은 줄 종류에 맞게 동작합니다: 제목 줄은 제목 수준, 목록 줄은 목록 단계, 코드 블록 안은 공백, 보통 문단과 표에서는 아무것도 하지 않습니다. 주석은 <!-- … --> 입니다. 대문자로·소문자로·대소문자 뒤집기는 명령 팔레트(Ctrl+K)에서 찾습니다. 검색 > 짝으로 이동(Ctrl+M)은 커서가 있는 짝의 반대편으로 갑니다: HTML 태그(<div> ↔︎ </div>), 코드 블록의 여는 줄 ↔︎ 닫는 줄, 수식 $$ 줄, HTML 주석(<!-- ↔︎ -->), 괄호 () [] {}. 편집기 오른쪽 클릭 메뉴에는 늘 줄 복제·줄 지우기가 있고, 선택한 텍스트가 있으면 같은 단어 모두 선택·선택한 줄마다 커서도 나옵니다.

여러 커서와 열 블록

메뉴 막대에는 없고 단축키와 명령 팔레트(Ctrl+K)로 씁니다.

  • 단어 선택, 다음 같은 단어 선택(Alt+J), 마지막 선택 해제(Alt+Shift+J), 같은 단어 모두 선택(Ctrl+Alt+J): 같은 단어마다 커서를 두고 한 번에 고칩니다(대소문자 구분).
  • 선택한 줄마다 커서(Alt+Shift+G), 위에 커서 추가·아래에 커서 추가(Ctrl+Alt+↑ / ↓), Alt+클릭으로 커서를 추가합니다.
  • 열 블록(사각형 선택): Alt+Shift+끌기, 또는 열 블록 위로·아래로 넓히기(Alt+Shift+↑ / ↓, ← / →·Home·End·PageUp·PageDown도 됩니다). 한글은 두 칸으로 셉니다. 입력·지우기·복사·붙여넣기는 줄마다 합니다.
  • 열 블록 선택 모드(편집 메뉴): 켜면 수정 키 없이 끌어도 열 블록이 됩니다. 켜져 있는 동안 상태 표시줄에 열 블록 칩이 보이고, 클릭하면 끕니다. 이번 실행 동안만 유지됩니다.
  • Esc 는 여러 커서·열 블록을 끝내고 커서 하나만 남깁니다(열 블록 선택 모드는 켜진 채).

마우스 동작과 숨은 기능은 이 설명서 끝 부록: 단축키 페이지의 「제스처와 숨은 기능」 표에 모아 두었습니다.

자동 완성

Ctrl+Space. ``` 뒤에서는 코드 블록 언어 이름, [[# 뒤에서는 이 문서의 제목이 나옵니다.

문서 정리 도구

  • 서식 > 제목 ▸ > 제목 번호...: 제목 앞에 1. 1.1 같은 번호를 붙이거나 뗍니다(서식 8가지).
  • 도구 > 문제 자동 수정(F7): 줄 끝 공백·탭·빈 줄 겹침 같은 흔한 마크다운 문제를 고칩니다. 코드 블록 안은 건드리지 않습니다.
  • 도구 > 박스 트리 맞추기: ```boxtree 블록의 들여쓰기를 ├─ │ └─ 선으로 바꿉니다.
  • 파일 > 문서 정보: 글자·단어·문단·제목·링크 수와 읽는 시간.
