문제 해결과 자주 묻는 질문

자주 겪는 문제를 증상별로 모았습니다. 알림에 나온 문구로 찾습니다.

문서가 깨져 보이거나 열리지 않을 때

글자가 깨져 보입니다. 인코딩은 BOM, UTF-8, CP949 차례로 알아봅니다. 그 밖의 인코딩으로 쓴 문서는 글자가 깨지거나 읽기 전용으로 열릴 수 있습니다. 원래 프로그램에서 UTF-8 로 저장한 뒤 다시 엽니다.

읽기 전용으로 열려 고칠 수 없습니다.

  • 「읽을 수 없는 바이트가 있어 읽기 전용으로 열었습니다」가 나왔으면 손상된 문서입니다. 파일 > 다른 이름으로 저장...(Ctrl+Shift+S)으로 사본을 만들어 고칩니다.
  • 그 알림이 없었으면 편집 > 읽기 전용이 켜져 있습니다. 상태 표시줄의 자물쇠 아이콘을 클릭해 끕니다.

문서가 열리지 않습니다.

  • 「파일이 너무 커서 열 수 없습니다」: 열 수 있는 크기를 넘은 파일입니다.
  • 「응답이 없어 열기를 중단했습니다」: 파일을 읽는 데 너무 오래 걸렸습니다. 잠시 뒤 다시 엽니다.
  • 「파일을 찾을 수 없어 최근 목록에서 뺐습니다」: 파일이 옮겨졌거나 지워졌습니다. 파일 > 열기...(Ctrl+O)로 새 위치에서 엽니다.

다른 형식 문서를 가져오지 못할 때

  • 「이 PDF에는 텍스트 레이어가 없습니다」: 스캔한 PDF 입니다. 글자 인식(OCR)을 거친 PDF 나 원본 문서를 엽니다.
  • 「암호가 맞지 않습니다」: 암호를 다시 입력합니다. 암호가 걸린 Word·엑셀 문서는 원래 프로그램에서 암호를 푼 뒤 엽니다.
  • 「배포용 문서는 본문이 암호화되어 있어 가져올 수 없습니다」: 아래한글 배포용 문서는 열지 못합니다.
  • 「이 형식은 Pandoc으로 가져옵니다」: ODT·EPUB 같은 문서는 「Pandoc 사용」을 켜고 Pandoc 을 찾을 수 있어야 열립니다.
  • 「문서가 너무 큽니다」나 그림 일부가 빠진 경우는 다른 형식 문서 열기의 한도를 봅니다.

저장하지 못할 때

저장 실패 알림이 나옵니다. 알림에 파일 경로와 운영체제가 알려 준 이유가 나옵니다. 저장에 실패해도 디스크의 파일은 그대로이고 탭은 수정됨으로 남습니다. 파일 > 다른 이름으로 저장...(Ctrl+Shift+S)으로 쓸 수 있는 폴더에 저장합니다.

「지금 내용으로 덮어쓸까요?」라고 묻습니다. 저장하기 전에 다른 프로그램이 파일을 바꿨습니다. [덮어쓰기] 버튼은 지금 내용을 쓰고, [다시 불러오기] 버튼은 디스크 내용으로 바꿉니다.

「UTF-8로 바뀌어 저장되었습니다」가 나옵니다. CP949·UTF-16 문서도 저장은 UTF-8 로만 합니다. 원래 인코딩이 꼭 필요하면 다른 프로그램에서 변환합니다.

다른 프로그램이 파일을 바꿨다는 알림

  • 「외부에서 바뀌어 다시 불러왔습니다」: 고치지 않은 문서라 새 내용을 불러왔습니다.
  • 「파일이 바뀌었습니다」 창: 앱에서도 고친 문서입니다. [예] 버튼은 다시 불러오기, [아니요] 버튼은 지금 내용을 그대로 둡니다.
  • 「디스크에서 사라졌습니다. 저장하면 다시 만들어집니다.」: 탭의 내용은 그대로 남습니다.

묻는 방식은 「외부에서 수정했을 때」 설정으로 바꿉니다(세션 복원·자동 저장·복구 사본).

저장하지 않은 내용과 비정상 종료

  • 비정상 종료 뒤 다시 실행하면 복구 사본이 저절로 되살아납니다. 「내용을 확인하고 저장하세요」가 나오면 확인하고 저장합니다.
  • 「저장 안 함」을 선택해 닫은 문서는 되살릴 수 없습니다. 복구 사본은 탭을 닫거나 정상적으로 끝내면 지워집니다.
  • 「복구 사본을 암호화할 수 없어 만들지 못했습니다」가 나오면 그 실행 동안 복구 사본이 없습니다. 자주 저장합니다.
  • 「지난 실행이 비정상 종료되었습니다」가 나오면 진단 파일이 이 PC 에 남은 것입니다. 자동으로 보내지 않습니다. 도구 > 설정 > 시스템의 「로그 폴더 열기」·「크래시 폴더 열기」로 위치를 엽니다.

참고: 진단 파일에는 문서 내용이 들어갈 수 있습니다. 문의할 때는 무엇을 하다가 어떤 문구가 보였는지 적습니다.

내보낸 PDF 와 그림

  • 「한글 글꼴을 찾지 못했습니다」: PDF 에 넣을 한글 글꼴이 없습니다. 맑은 고딕·Noto Sans CJK KR·나눔고딕 중 하나를 설치합니다.
  • 「찾지 못해 넣지 않았습니다」: 없는 그림이나 문서 폴더 밖의 그림은 PDF 에 넣지 않습니다.
  • 웹 주소로 건 그림은 PDF 에 들어가지 않습니다. 도구 > 웹 그림 다운로드로 문서 옆에 내려받은 뒤 내보냅니다.
  • 미리보기에서 그림이 깨진 그림 표시로 나오면 문서를 저장하고 그림을 문서 폴더 안에 둡니다. 웹 주소, 폴더 밖, 저장하지 않은 문서의 그림은 미리보기에 보이지 않습니다.

AI 가 응답하지 않을 때

  • 「키가 없습니다」: 도구 > 설정 > AI에서 키를 저장합니다. [연결 테스트] 버튼을 클릭해 「연결됨」이 나오는지 확인합니다.
  • 「설정 > AI에서 [다시 찾기]를 클릭하세요」: 쓰려는 CLI 가 설치돼 있는지 확인하고 도구 > 설정 > AI에서 [다시 찾기] 버튼을 클릭합니다.
  • 「먼저 AI로 다룰 텍스트를 선택하세요」: 편집기에서 텍스트를 선택한 뒤 다시 실행합니다.
  • 「답이 출력 한도에서 잘렸습니다」: 「최대 출력 토큰」을 늘립니다.

AI 앱이 MDStudio 에 연결되지 않을 때

  • 상태 표시줄의 서버 아이콘에 「MCP 서버 꺼짐」이 나오면 도구 > MCP 서버를 클릭해 켭니다.
  • 「MCP 서버를 열 수 없습니다」: 포트가 다른 프로그램과 겹칠 수 있습니다. 도구 > 설정 > MCP에서 「포트」를 바꾸고 [복사] 버튼으로 연결 설정을 다시 붙여 넣습니다.
  • 문서를 고치는 도구가 보이지 않으면 「쓰기 도구 허용」을 선택합니다.
