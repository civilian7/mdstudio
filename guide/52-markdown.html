마크다운 문법 요약

마크다운은 텍스트 파일 하나로 된 문서 형식입니다. 메모장으로 열어도 읽히고, 고친 자리가 줄 단위로 드러납니다. 문법은 세 가지가 있습니다: 표준(CommonMark), GFM(GitHub — 표·할 일 목록·취소선), 몇몇 도구만 아는 확장(수식 등).

글자와 문단

쓰는 법 결과
**굵게** 굵게
*기울임* 기울임
~~취소선~~ (GFM) 취소선
`코드` 코드
빈 줄 문단 나누기
줄 끝 공백 두 개 또는 \ 문단 안 줄 바꿈

제목·목록·인용

# 제목 1
## 제목 2

- 글머리 목록
  - 들여쓰면 아래 단계
1. 번호 목록
- [ ] 할 일 (GFM)
- [x] 한 일

> 인용

코드와 표

```rust
fn main() {}
```

| 이름 | 값 |
|---|--:|
| 가 | 1 |

표의 --: 는 오른쪽 정렬, :-: 는 가운데 정렬입니다.

수식 (확장)

$a^2+b^2=c^2$ 는 인라인 수식, $$ … $$ 는 블록 수식입니다. 다른 도구에서는 기호가 글자로 보일 수 있습니다.

확장 문법

미리보기가 그리는 표준 밖 문법입니다. GitHub 같은 곳에서는 기호가 글자로 보입니다.

문법 보이는 모양
==형광== 형광펜
++밑줄++ 밑줄
H~2~O · 9m^2^ 아래첨자 · 위첨자(안에 공백 없음, ~~ 는 취소선)
#태그 태그 칩
%%주석%% 숨김(%% 한 줄로 감싸면 여러 줄)
문장 ^블록-id 문단 끝 블록 참조(흐리게)
## 제목 {#아이디} 제목 아이디 — [가기](#아이디) 로 이동

언어 없이 첫 줄이 괘선(┌─┐)인 코드 블록과 ```boxtable·```boxtree 는 줄 사이 틈 없이 그립니다.

::: note 제목
note · tip · warning · caution · details(접기) · columns(나란한 열)
:::

용어
:   뜻풀이

::: columns 안에 ::: column 상자를 여러 개 두면 한 열씩 나란히 놓입니다. 모르는 이름은 테두리 상자로 그립니다.

흔한 실수

  • 제목 기호 뒤에 공백이 없음: #제목 → # 제목.
  • 목록 앞뒤에 빈 줄이 없어 문단에 붙음.
  • 들여쓰기를 탭과 공백으로 섞음 — 도구 > 문제 자동 수정(F7)이 고칩니다.
