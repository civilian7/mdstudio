AI 에이전트 연결(MCP)

Claude Desktop·Claude Code 같은 AI 에이전트가 열린 문서를 읽고 고치게 하는 연결입니다. 표준 MCP(Model Context Protocol)를 씁니다.

켜기

  1. 도구 > 설정... > MCP 에서 「MCP 서버 켜기」를 켭니다(또는 도구 > MCP 서버). 서버는 이 PC 안(127.0.0.1)에서만 받고 토큰이 있어야 연결됩니다.
  2. 같은 페이지 AI 앱 연결에서 쓰는 앱(Claude Desktop·Claude Code·Codex) 줄의 **[복사]**를 클릭하면 그 앱에 넣을 설정(또는 명령)이 클립보드에 들어갑니다. Claude Desktop 은 설정 파일(claude_desktop_config.json)에 붙여 넣고, Claude Code 는 터미널에서 실행하고, Codex 는 ~/.codex/config.toml 에 붙여 넣습니다. 토큰 값은 들어가지 않습니다 — 연결 프로그램이 이 PC 의 보안 저장소에서 읽습니다. Claude Desktop 것은 명령 팔레트(Ctrl+K)의 Claude Desktop 연결 설정 복사로도 받습니다. (Microsoft Store 밖 배포판에는 줄마다 [등록] 버튼도 있어, 확인을 받은 뒤 그 앱의 설정에 직접 넣습니다.)

도구 그룹

그룹 예
읽기 list_documents·read_document·get_outline·get_selection·get_stats·search_document·check_links·get_problems·get_links·get_front_matter
문서 수정 insert_text·insert_section·replace_all·edit_document·auto_fix·number_headings·표 도구·section(절 단계 올리기/내리기·옮기기·지우기)·set_front_matter(문서 속성)
그림 render_picture(Mermaid·Graphviz·수식을 PNG 로 — 문서는 바뀌지 않습니다)
앱 새 문서·열기(아래한글·Word·PDF·엑셀은 .md 로 바꿔 엶)·저장(TextBundle·TextPack 포함)·닫기·내보내기·명령 실행 등

쓰기·실행 도구는 설정에서 「쓰기 도구 허용」을 켰을 때만 목록에 나오고, 켜 두어도 호출마다 확인을 받습니다. 확인 창은 [취소]에 초점이 있고 Enter 로 허락되지 않습니다. 오래 답이 없거나 그 사이 문서가 바뀌면 거절합니다. 에이전트가 더 기다리지 않으면 확인 창을 닫고, 그 뒤에 허락해도 아무것도 바꾸지 않습니다. 읽기 전용으로 둔 문서는 묻지 않고 거절합니다.
