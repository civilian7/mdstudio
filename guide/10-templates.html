템플릿과 스니펫

  • 템플릿은 새 문서의 틀입니다: 파일 > 템플릿으로 새 문서...(Ctrl+Shift+N).
  • 스니펫은 커서 자리에 삽입하는 블록입니다(표·다이어그램 틀 등): 서식 > 스니펫...(Ctrl+Shift+A)

기본으로 회의·보고(월간 업무 보고·출장 보고서·의사결정 요청서), 기술 문서(CLI 도구 사용법·설정 레퍼런스·릴리스 체크리스트), 글쓰기(칼럼·제품 리뷰·뉴스레터), 개발 일지(하루·버그 추적·주간 요약) 템플릿과 해당 분야의 스니펫(참석자 표·매개변수 표·HTTP 상태 코드 표·TIL 등)이 들어 있습니다.

템플릿·스니펫 안의 토큰은 넣을 때 채워집니다.

토큰 값
{{날짜}} {{date}} 오늘 날짜(2026-11-03)
{{시각}} {{time}} 현재 시각(09:05)
{{요일}} {{weekday}} 요일
{{년}} {{year}} 올해
{{작성자}} {{author}} 설정의 이름(비면 Windows 계정)
{{소속}} {{org}}, {{이메일}} {{email}} 설정의 소속·이메일
{{커서}} {{cursor}} 넣은 뒤 커서가 놓일 자리

이름·소속·이메일은 도구 > 설정... > 일반에 적습니다.

파일 형식

템플릿 하나가 곧 .md 파일 하나이고, 그룹은 폴더입니다(한 겹). 파일 맨 위에 메타데이터 블록을 둘 수 있습니다.

<!-- lumi:
  name: 주간 보고
  summary: 한 주의 한 일과 할 일
  order: 10
  saveAs: 주간보고.md
-->
# {{날짜}} 주간 보고

{{커서}}

템플릿으로 새 문서 창 (고르기와 관리 한 창)

파일 > 템플릿으로 새 문서... 한 창에서 고르고 관리합니다(별도 관리 메뉴는 없습니다). 왼쪽은 트리(기본 템플릿·내 것 → 그룹 → 템플릿), 오른쪽은 내용 앞 200줄 미리 보기, 위에 찾기 칸과 도구 줄, 아래에 [만들기]·[취소] 입니다. 서식 > 스니펫... 도 같은 창이고 단추만 [삽입] 입니다. 위의 템플릿 | 스니펫 칩으로 오갑니다.

  • 만들기: 고르고 [만들기](Enter·더블클릭). 찾기 칸에 치면 이름·설명·검색어·그룹으로 거릅니다.
  • 기본 템플릿은 프로그램에 딸린 것이라 편집할 수 없습니다. 내 것으로 복제한 뒤 복제본을 고칩니다(같은 이름이면 내 것이 이깁니다).
  • 편집기에서 열기(내 것만): 템플릿은 보통 마크다운 문서처럼 탭에서 고칩니다(창은 닫힙니다).
  • 새 그룹·새 템플릿: 기본 템플릿을 고른 채 눌러도 같은 갈래의 「내 것」에 만듭니다. 새 템플릿은 # {{커서}} 로 시작하고 목록에 고른 채로 둡니다(창은 그대로, 내용은 편집기에서 열기로 씁니다).
  • 이름 바꾸기(F2)는 내 것만. 삭제(Delete): 내 것은 지우고(되돌릴 수 없음, 그룹은 안의 것까지), 기본 템플릿은 목록에서 숨깁니다. 숨긴 기본 템플릿은 흐리게 「숨김」으로 보이고 다시 보이기로 되돌립니다(숨긴 것은 만들 수 없습니다).
  • 내 템플릿 폴더 열기: 파일 탐색기로 내 폴더를 엽니다.
  • 항목을 오른쪽 단추로 누르면 같은 동작과 모두 접기·모두 펼치기가 있습니다.
  • 옛 명령 「템플릿 관리」(명령 팔레트·단축키)도 같은 창을 엽니다.
