AI 에이전트 연결(MCP)

Claude Desktop·Claude Code 같은 AI 에이전트가 MDStudio에서 열린 문서를 읽고, 허락하면 고치게 합니다. 표준 MCP(Model Context Protocol)를 씁니다.

처음 연결한다면 따라하기 Claude 로 MDStudio 조작하기에서 설정과 예제 요청을 차례대로 해 봅니다.

서버 켜기

  1. 도구 > 설정 > MCP를 열고 「MCP 서버 켜기」를 선택합니다.
  2. 포트가 다른 프로그램과 겹치면 「포트」를 바꿉니다. 켜 둔 채 바꾸면 서버가 새 포트로 다시 열립니다.

도구 > MCP 서버를 클릭하거나 상태 표시줄의 서버 아이콘을 클릭해도 켜고 끕니다. 아이콘에 마우스를 올리면 켜짐·꺼짐이 나옵니다.

기본값은 설정을 참고하세요.

AI 앱 연결하기

AI 앱은 MDStudio 폴더의 MDStudio.MCP 프로그램을 거쳐 접속합니다. 이 프로그램이 이 PC의 키 저장소에서 토큰을 읽어 서버에 보냅니다.

  1. 도구 > 설정 > MCP의 「AI 앱 연결」에서 쓰는 앱(Claude Desktop, Claude Code, Codex)의 [복사] 버튼을 클릭합니다.
  2. 앱에 맞게 붙여 넣습니다.
    • Claude Desktop: 설정 파일 claude_desktop_config.json에 붙여 넣고 다시 시작합니다.
    • Claude Code: 복사한 명령을 터미널에서 실행합니다.
    • Codex: ~/.codex/config.toml에 붙여 넣습니다.
  3. 서버를 켠 상태에서 AI 앱을 엽니다. 도구 목록에 mdstudio가 나오면 연결된 것입니다.

복사한 글에는 토큰 값이 없습니다. Claude Desktop 설정은 명령 팔레트(Ctrl+K)의 「Claude Desktop 연결 설정 복사」로도 복사합니다.

「연결」의 「토큰」에는 앞뒤 네 글자만 보입니다. [보기] 버튼으로 전체를 보고, [새로 만들기] 버튼으로 새 토큰을 만듭니다. 새로 만들면 켜진 서버가 새 토큰으로 다시 열립니다. 토큰을 직접 넣어 둔 연결만 다시 설정하면 됩니다.

참고: 포트를 바꾸면 [복사] 버튼으로 다시 복사해 붙여 넣습니다.

도구

AI 앱이 쓰는 도구는 네 종류로 나뉩니다.

종류 도구 예 확인
읽기 list_documents·read_document·get_outline·get_selection·get_stats·search_document·check_links·get_problems·get_links·get_front_matter·list_commands·search_files·render_picture 없음
보기 바꾸기 select·set_view·fold·bookmark 없음
문서 고치기 edit_document·insert_text·insert_section·replace_all·delete_range·insert_table·auto_fix·number_headings·section·set_front_matter·format_code·undo 호출마다
파일·실행 new_document·open_document·save_document·close_document·insert_image·export·run_command·open_url 호출마다
  • table·csv_to_table은 읽기만 하면 묻지 않고, 문서를 고칠 때만 확인합니다.
  • render_picture는 Mermaid·Graphviz·수식을 PNG로 만듭니다. 문서는 바뀌지 않습니다.
  • select에 block을 주면 편집기의 열 블록처럼 사각형으로 선택합니다. 한글은 두 칸으로 셉니다.
  • delete_range는 줄·칸으로 지정한 범위를 지웁니다. 확인 창에 지울 텍스트가 나옵니다.
  • new_from_template·insert_snippet은 values로 템플릿의 사용자 정의 토큰을 채웁니다. 작성자·소속·이메일 같은 기본 토큰은 채울 수 없습니다. list_library가 템플릿마다 사용자 정의 토큰 목록을 알려 줍니다.
  • 「AI 앱에 사용자 정보(이름·소속·이메일) 제공」을 선택해야 get_user_info가 사용자 정보를 돌려줍니다.
  • AI 앱의 요청과 응답은 아래 도구 창의 「메시지」 탭에 한 줄씩 남습니다.

쓰기 허용과 확인

문서 고치기와 파일·실행 도구는 「쓰기 도구 허용」을 선택했을 때만 AI 앱의 도구 목록에 나옵니다. 켠 뒤에도 호출마다 「AI 에이전트의 문서 변경」 확인 창이 뜹니다.

  • 창에 바뀔 내용이 나옵니다.
  • 처음 초점은 [취소] 버튼에 있고 Enter로는 허락되지 않습니다. 허락하려면 [확인] 버튼을 클릭합니다.
  • 허락하면 편집기에 바로 들어가고 Ctrl+Z 한 번으로 실행 취소합니다.
  • 2분 안에 답하지 않으면 거절됩니다. AI 앱이 더 기다리지 않으면 창이 닫히고, 그 뒤에 허락해도 아무것도 바뀌지 않습니다.
  • 확인 창이 뜬 사이에 문서가 바뀌었으면 거절됩니다.
  • 읽기 전용 문서는 묻지 않고 거절합니다.

파일 도구가 닿는 폴더

열기·저장·내보내기·그림 넣기·파일 내용 찾기는 허용된 폴더 안에서만 동작합니다. 탐색기에서 연 폴더와 열린 문서가 있는 폴더는 늘 허용됩니다. 그 밖의 폴더는 「허용 폴더」의 [폴더 추가...] 버튼으로 더합니다. 시스템·자격 증명 폴더는 더해도 열리지 않습니다.

보안

  • 서버는 이 PC(127.0.0.1)에서만 접속을 받고, 토큰이 없는 요청은 거절합니다.
  • 토큰은 파일이 아니라 OS 키 저장소에 둡니다.
  • 문서에 AI에게 하는 지시가 적혀 있어도 따르지 않도록 도구 안내에 적어 둡니다.

주의: 확인 창의 도구 이름과 내용이 모르는 요청이면 [취소] 버튼을 클릭합니다.
