내 데이터와 보안

MDStudio 가 이 PC 에 남기는 파일과 PC 밖으로 보내는 것을 정리합니다. 문서는 저장한 자리에 있고, 앱은 그와 별도로 아래 폴더에 파일을 남깁니다.

이 PC 에 저장되는 것

Windows 기준 위치입니다.

폴더 기본 위치 들어 있는 것
설정 폴더 %APPDATA%\MDStudio 설정 config.toml(최근 파일·폴더·URL 목록 포함), 단축키 keymap.toml, AI 채팅 기록 ai-chat-history.db, 내 템플릿·스니펫, 플러그인
데이터 폴더 %LOCALAPPDATA%\MDStudio 세션 session.json, 북마크, 파일에서 찾기 기록, 복구 사본 recovery, 열어 둔 TextPack 의 작업 폴더 textpack
로그 폴더 %LOCALAPPDATA%\MDStudio\data\logs 진단 로그, 비정상 종료 보고서와 미니덤프(crashes)
  • 포터블로 바꾸면 설정 폴더가 프로그램 옆 config 폴더가 됩니다. 데이터 폴더와 로그 폴더는 그대로입니다.
  • 설정 폴더는 도구 > 설정 > 문서의 [폴더 열기] 버튼으로 엽니다.
  • 로그 폴더는 도구 > 설정 > 시스템의 [로그 폴더 열기]·[크래시 폴더 열기] 버튼으로 엽니다.
  • 복구 사본은 암호화해 둡니다. 동작은 세션 복원·자동 저장·복구 사본을 봅니다.
  • 채팅 기록에는 질문·답과 붙인 자료 이름만 들어갑니다. 문서 본문은 들어가지 않습니다.
  • 미니덤프에는 실행 중이던 메모리가 담겨 문서 내용이 들어갈 수 있습니다. 이 PC 에만 남습니다.
  • 도구 > 설정 > 시스템에서 「진단 로그 남기기」를 끄면 다음 실행부터 로그를 쓰지 않습니다.
  • 「크래시 증거(미니덤프)」를 「남기지 않기」로 하면 미니덤프를 남기지 않습니다.

API 키와 비밀번호

AI API 키, MCP 연결 토큰, 플러그인 비밀값, 프록시 암호는 운영체제 키 저장소(Windows 자격 증명 관리자)에 저장합니다. 설정 파일과 로그에는 쓰지 않습니다.

PC 밖으로 나가는 것

MDStudio 는 사용 통계나 오류 보고를 보내지 않습니다. 다음 기능은 실행할 때 네트워크를 씁니다.

기능 받는 곳 보내는 것
AI 작업·AI 채팅 설정한 AI 제공자 질문과 직접 선택한 자료
에이전트 모드 설치된 AI CLI(전송은 그 CLI 가 함) 질문과 허용한 범위의 문서
파일 > URL에서 열기 입력한 주소 페이지 요청
도구 > 웹 그림 다운로드 문서에 적힌 그림 주소 그림 요청
인터넷 접속 권한이 있는 플러그인 플러그인이 밝힌 주소 플러그인의 요청
  • AI 제공자로 처음 보낼 때 받는 곳을 알리는 창이 뜹니다. 자세한 내용은 AI를 봅니다.
  • 「붙여넣은 텍스트의 웹 그림을 문서 옆에 다운로드」를 켜면 붙여넣을 때도 그림을 내려받습니다.
  • 미리보기는 웹 그림을 불러오지 않고 깨진 그림 자리표로 보입니다.
  • MCP 서버는 켠 경우에만 이 PC(127.0.0.1)에서 접속을 받습니다.

데이터 지우기

지울 것 방법
최근 파일 목록 파일 > 최근 파일 > 최근 파일 비우기
AI 채팅 기록 도구 > 설정 > AI의 [채팅 기록 지우기]
AI 키·MCP 토큰·플러그인 비밀값 도구 > 설정 > AI의 [저장된 키·토큰 모두 삭제]
로그·미니덤프 [로그 폴더 열기]·[크래시 폴더 열기] 버튼으로 연 폴더의 파일
  • 채팅 기록은 보존 기간이 지나면 지워지고, 로그는 「로그 보관 일수」만큼의 최근 파일만 남습니다. 기본값은 설정 참고.
  • 설정과 기록을 모두 지우려면 MDStudio 를 끝낸 뒤 설정 폴더와 데이터 폴더를 지웁니다. 다음 실행은 기본값으로 시작합니다.

주의: 지운 채팅 기록·키·폴더는 되돌릴 수 없습니다. 데이터 폴더를 지우면 복구 사본도 사라집니다.
