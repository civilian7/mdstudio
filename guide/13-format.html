서식

굵게·기울임 같은 글자 서식, 제목, 목록, 인용을 넣고 제목에 번호를 매기는 방법과 붙여넣기 규칙을 설명합니다. 서식 명령은 마크다운 기호를 텍스트에 직접 붙이거나 뗍니다. 표는 표, 줄 편집과 자동 완성은 편집을 봅니다.

참고: 서식 명령은 편집기가 보이는 마크다운 문서에서만 켜집니다. 미리보기만 보기, 읽기 전용 문서, 소스 코드·일반 텍스트 문서에서는 메뉴가 흐려집니다.

글자 서식 넣기

  1. 서식을 넣을 텍스트를 선택합니다.
  2. 서식 > 굵게(Ctrl+B)를 클릭합니다.

이렇게 보입니다: 선택한 텍스트 앞뒤에 ** 가 붙고, 커서는 닫는 기호 뒤에 놓입니다.

명령 단축키 붙는 기호
굵게 Ctrl+B **텍스트**
기울임 Ctrl+I *텍스트*
취소선 Alt+D ~~텍스트~~
인라인 코드 Alt+C `텍스트`
링크 Alt+L [텍스트]()

굵게·기울임·취소선·인라인 코드는 서식 메뉴에 있습니다. 링크 명령은 메뉴에 없고 단축키나 미니 도구 모음의 링크 버튼으로 씁니다. 주소와 제목을 입력 창에서 정하려면 서식 > 링크를 쓰고, 자세한 방법은 삽입을 봅니다.

  • 텍스트를 선택하지 않고 단어 안이나 단어 끝에 커서를 두면 그 단어에 적용합니다. 단어가 없는 자리에서는 기호 한 쌍만 넣고 그 사이에 커서를 놓습니다.
  • 기호까지 포함해 선택하거나 기호로 감싼 단어 안에 커서를 두고 같은 명령을 한 번 더 실행하면 기호를 뗍니다.
  • 링크 명령은 선택한 텍스트를 [텍스트]() 로 바꾸고 커서를 주소 자리에 놓습니다. 같은 명령으로 떼지는 않습니다.

제목 만들기

  1. 제목으로 만들 줄에 커서를 둡니다. 여러 줄이면 모두 선택합니다.
  2. 서식 > 제목 > 제목 2(Alt+2)를 클릭합니다.

이렇게 보입니다: 줄 앞에 ## 이 붙습니다.

  • 제목 1~6 은 Alt+1~Alt+6 입니다. 서식 > 제목 > 본문(Alt+0)은 제목 기호를 뗍니다.
  • 이미 제목인 줄에 다른 수준을 주면 기호가 바뀝니다. # 제목 에 제목 3 을 주면 ### 제목 이 됩니다. 같은 수준을 한 번 더 주면 본문이 됩니다.

목록과 인용 만들기

  1. 줄에 커서를 두거나 여러 줄을 선택합니다.
  2. 서식 > 글머리 기호 목록(Alt+7)을 클릭합니다.

이렇게 보입니다: 줄마다 - 가 붙습니다.

명령 단축키 줄 앞에 붙는 기호
글머리 기호 목록 Alt+7 -
번호 목록 Alt+8 1. 2. …
할 일 목록 Alt+9 - [ ]
인용 Alt+Q >

네 명령 모두 서식 메뉴에 있습니다. 같은 명령을 한 번 더 실행하면 기호를 뗍니다. 다른 목록·인용·제목 명령을 주면 기호가 쌓이지 않고 바뀝니다.

줄을 오른쪽 클릭해도 서식을 바꿉니다. 제목 줄에는 「제목 수준 올리기」, 「제목 수준 내리기」, 「본문으로 바꾸기」가, 보통 문단에는 「제목 1로」, 「글머리 기호 목록으로」, 「인용으로」, 「코드 블록으로」 같은 명령이, 인용 줄에는 「인용 풀기」가 나옵니다. 할 일 줄에서는 「완료로 표시」와 「미완료로 표시」를 선택합니다.

코드 블록과 가로줄 넣기

  • 서식 > 코드 블록(Alt+K): 선택한 텍스트를 ``` 울타리로 감쌉니다. 언어 이름은 적지 않으므로, 울타리 안을 오른쪽 클릭하고 「언어 바꾸기」를 선택해 정합니다.
  • 서식 > 가로줄(Alt+R): 커서 자리에 --- 줄을 넣습니다. 텍스트를 선택했으면 선택한 텍스트가 가로줄로 바뀝니다.

제목에 번호 매기기

  1. 제목이 있는 문서에서 서식 > 제목 > 제목 번호를 클릭합니다. 제목 줄을 오른쪽 클릭해 「제목 번호 매기기...」를 선택해도 같은 창이 열립니다.
  2. 「제목 번호」 창 왼쪽 목록에서 서식을 선택합니다. 오른쪽에 결과 미리보기가 나옵니다.
  3. **[확인]**을 클릭합니다.

이렇게 보입니다: 제목 앞에 번호가 붙고, 몇 개에 번호를 매겼는지 알림이 나옵니다. 제목이 없는 문서에서는 이 메뉴가 흐립니다.

서식은 「번호 제거」, 「십진」, 「십진(꼬리 점 없음)」, 「공문서」, 「장·절」, 「영문 개요」, 「보고서」, 「Word 목록」 여덟 가지입니다.

  • 번호는 제목 텍스트 앞에 실제 글자로 들어갑니다. 십진은 제목 1 을 문서 제목으로 보고 제목 2 부터 매겨 ## 1. 개요, ### 1.1. 배경 이 됩니다. 장·절은 제목 1 부터 매겨 # 제1장 서론, ## 제1절 배경 이 됩니다.
  • 이미 번호가 있는 제목에 다시 매기면 번호가 쌓이지 않고 바뀝니다. 「번호 제거」는 번호만 뗍니다. 코드 블록 안의 # 줄은 건드리지 않습니다.
  • 문서 안의 제목 링크(](#…))는 바뀐 제목에 맞게 함께 고치고, 고친 개수를 알림에 덧붙입니다.

붙여넣기

  • 편집 > 코드 블록으로 붙여넣기(Ctrl+Shift+V): 클립보드 텍스트를 코드 블록으로 넣습니다. 언어는 확실할 때만 적고 아니면 text 로 적습니다.
  • 엑셀처럼 탭으로 나뉜 텍스트를 Ctrl+V 로 붙이면 첫 줄이 머리글인 표로 바뀝니다. 두 줄 이상이고 모든 줄의 칸 수가 같을 때만 바뀌며, 코드 블록 안에서는 바뀌지 않습니다. 300줄이나 100KB 를 넘으면 「큰 표 붙여넣기」 창이 먼저 묻습니다. **[확인]**은 표로 바꿔 붙이고 **[취소]**는 아무것도 붙이지 않습니다.
  • 클립보드에 그림만 있으면 그림 파일로 저장해 문서에 넣습니다. 저장하지 않은 문서는 「문서를 먼저 저장해야 그림을 넣을 폴더가 정해집니다」 알림이 나옵니다.
  • 그 밖의 붙여넣기는 텍스트만 들어옵니다. 다른 프로그램의 굵게·색 같은 서식은 붙지 않으므로, 붙인 뒤 이 페이지의 명령으로 서식을 넣습니다.

관련 페이지

  • 줄 편집, 자동 완성, 여러 커서는 편집을 봅니다.
  • 표를 만들고 고치는 방법은 표를 봅니다.
  • 그림·링크·기호·다이어그램은 삽입을 봅니다.
  • 마크다운 문법 전체는 마크다운 문법 요약을 봅니다.
