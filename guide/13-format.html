서식

서식 명령은 선택한 텍스트(없으면 커서 자리)에 마크다운 기호를 붙이거나 뗍니다. 같은 명령을 한 번 더 클릭하면 떼어집니다.

명령 단축키 기호
굵게 Ctrl+B **글**
기울임 Ctrl+I *글*
취소선 Alt+D ~~글~~
코드 Alt+C `글`
링크 Alt+L [글](주소)
본문 / 제목 1~6 Alt+0 / Alt+1~6 # … ######
글머리·번호·할 일 목록 Alt+7 / Alt+8 / Alt+9 - · 1. · - [ ]
인용 Alt+Q >
코드 블록 Alt+K ```
가로줄 Alt+R ---

붙여넣기와 복사

  • 편집 > 코드 블록으로 붙여넣기(Ctrl+Shift+V): 클립보드 텍스트를 코드 블록으로 넣고 언어를 짐작해 적습니다.
  • 엑셀처럼 탭으로 구분된 텍스트를 Ctrl+V 하면 표로 바뀝니다(300줄 또는 100 KB 를 넘으면 먼저 묻습니다). 그림만 있는 클립보드는 그림 파일로 넣습니다.
