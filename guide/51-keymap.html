단축키 바꾸기

명령마다 단축키를 바꾸거나 지웁니다. 단축키는 설정 창의 단축키 쪽에서 바꿉니다.

참고: 바꾼 단축키는 바로 적용되고 바로 저장됩니다. 설정 창의 **[취소]**를 눌러도 남습니다.

단축키 쪽 열기

  1. 도구 > 설정(Ctrl+,)을 선택합니다.
  2. 설정 창의 「단축키」 범주를 클릭합니다.

명령 팔레트(Ctrl+K)에서 「단축키 설정...」을 실행해도 같은 쪽이 열립니다.

단축키 바꾸기

  1. 찾기 칸(「명령 이름·ID·메뉴·키로 찾기」)에 명령 이름, ID, 메뉴, 키를 입력합니다. 예: format.bold, ctrl-b
  2. 목록에서 명령을 고르고 **[키 지정]**을 클릭합니다. Enter를 누르거나 명령을 두 번 클릭해도 됩니다.
  3. 「키를 누르세요…」 칸이 나오면 바꿀 키를 누릅니다. Esc를 누르면 지정을 멈춥니다.
  4. **[바꾸기]**는 이 명령의 키를 누른 키 하나로 바꿉니다. **[추가]**는 누른 키를 현재 키에 더합니다.
  5. 다른 명령이 같은 키를 쓰면 「단축키 겹침」 창이 뜹니다. **[확인]**을 누르면 그 명령에서 키를 빼고 지정합니다.

지우기와 기본값

  • **[지우기]**는 고른 명령의 키를 모두 없앱니다. 확인 창은 뜨지 않습니다.
  • 목록에서 Delete를 누르면 「단축키 지우기」 창이 뜹니다. **[확인]**을 눌러야 지워집니다.
  • **[기본값]**은 고른 명령 하나를 기본 키로 되돌립니다. 바꾼 명령에서만 누를 수 있습니다.
  • **[모두 기본값으로]**는 바꾼 단축키 전부를 되돌립니다. 「모든 단축키를 기본값으로」 창에서 **[확인]**을 누릅니다.

목록에서 바꾼 명령의 키 앞에는 ● 표시가 붙습니다. 경고 아이콘은 같은 문맥에서 키가 겹친다는 뜻입니다.

쓸 수 없는 키

누르면 이유가 나오고 지정되지 않습니다.

키 이유
Ctrl·Alt 없이 누른 글자, Enter, Tab, Esc, 방향 키 편집기와 입력란이 씁니다. F1~F24는 혼자 써도 됩니다
Ctrl+C, V, X, Z, Y, A 복사·붙여넣기·실행 취소 같은 편집 필수 키입니다
Alt+Tab, Alt+F4 등 운영 체제가 쓰는 키입니다
Alt와 메뉴 막대 글자 메뉴 막대 접근 키입니다
한 번에 누르는 키 4개 이상 한 번에 누르는 키는 3개까지입니다

파일로 고치기

  1. 명령 팔레트(Ctrl+K)에서 「단축키 파일 열기」를 실행합니다. 파일이 없으면 만들어서 편집기 탭으로 엽니다.
  2. "format.bold" = ["ctrl-shift-b"] 형식으로 적습니다. 빈 목록 []은 키 없음입니다.
  3. 저장하고 명령 팔레트에서 「단축키 다시 불러오기」를 실행합니다. 모르는 명령이나 쓸 수 없는 키는 빼고 적용합니다.

주의: 설정 창에서 단축키를 바꾸면 앱이 keymap.toml을 새로 씁니다. 직접 적은 주석은 그때 사라집니다.

편집기 키 배치

[편집기 프리셋...](단축키 쪽 아래)을 클릭하면 Visual Studio, Borland, JetBrains, VS Code 배치를 고를 수 있습니다. 바뀌는 명령 수를 보고 **[확인]**을 누릅니다. 명령 팔레트에는 없습니다.

부록에서 단축키 보기

F1을 누르고 목차 맨 끝의 「부록: 단축키」를 봅니다. 명령 팔레트의 「단축키 목록」도 같습니다. 키가 있는 명령만 메뉴별로 나오며, 표는 창을 열 때 만들어집니다.
