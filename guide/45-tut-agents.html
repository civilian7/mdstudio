AI 에이전트(Claude·Codex·Gemini CLI)로 MDStudio 조작하기

Claude Desktop·Claude Code·Codex CLI·Gemini CLI 같은 AI 에이전트를 MDStudio 에 연결하고, 말로 부탁해서 문서를 고치고 내보냅니다. 약 15분 걸립니다. 이 PC에 이 가운데 하나가 설치돼 있어야 합니다.

참고: 연습 파일은 앱에서 F1 로 이 페이지를 열면 받을 수 있습니다(연습 파일 열기 링크).

할 수 있는 것

  • 에이전트가 MDStudio 에 열린 문서를 읽고 요약하거나, 표·문제·선택 영역을 고치고, 템플릿으로 새 문서를 만들고, PDF 로 내보냅니다.
  • 에이전트가 문서나 파일을 바꾸려 할 때마다 MDStudio 가 확인 창을 띄웁니다. [확인] 버튼을 클릭해야 바뀝니다.
  • 바뀐 내용은 Ctrl+Z 한 번으로 실행 취소합니다.
  • 네 에이전트 모두 같은 MCP 도구를 씁니다. 연결 방법만 다르고 3단계부터는 같습니다.

준비

  1. 위의 연습 파일 열기 링크를 클릭합니다.

이렇게 보입니다: MDStudio 따라하기\45-tut-agents 폴더의 주간 보고.md 탭이 열립니다. 같은 폴더의 양식 폴더에는 5단계에서 쓸 견적서.md 가 있습니다.

1단계: MCP 서버 켜기

  1. 도구 > 설정(Ctrl+Alt+S)을 클릭합니다.
  2. 왼쪽 목록에서 「MCP」를 클릭합니다.
  3. 「MCP 서버 켜기」를 선택합니다.
  4. 「쓰기 도구 허용」을 선택합니다. 선택하지 않으면 에이전트는 문서를 읽기만 합니다.

이렇게 보입니다: 상태 표시줄의 서버 아이콘에 색이 들어옵니다. 마우스를 올리면 「MCP 서버 켜짐」이 나옵니다.

2단계: 에이전트에 MDStudio 연결하기

설정 창의 같은 페이지 아래 「AI 앱 연결」에서 쓰는 에이전트 줄의 [복사] 버튼을 클릭하고, 아래에서 그 에이전트의 절을 따라 합니다. 복사한 글에는 토큰 값이 없습니다.

Claude Desktop

  1. 「Claude Desktop」 줄의 [복사] 버튼을 클릭합니다.
  2. Claude Desktop 의 설정 파일 claude_desktop_config.json 을 엽니다. Windows 에서는 %APPDATA%\Claude 폴더에 있습니다.
  3. 파일이 비어 있으면 복사한 글을 그대로 붙여넣습니다. 이미 "mcpServers" 가 있으면 그 안에 "mdstudio" 항목만 넣습니다.
  4. 파일을 저장하고 Claude Desktop 을 완전히 끈 뒤 다시 시작합니다.

Claude Code

  1. 「Claude Code」 줄의 [복사] 버튼을 클릭합니다. claude mcp add --scope user mdstudio -- 로 시작하는 명령이 복사됩니다.
  2. 터미널에 붙여넣고 실행합니다.
  3. claude mcp list 를 실행해 목록에 mdstudio 가 있는지 확인합니다.

Codex CLI

  1. 「Codex」 줄의 [복사] 버튼을 클릭합니다. [mcp_servers.mdstudio] 로 시작하는 설정이 복사됩니다.
  2. Codex 의 설정 파일 config.toml 을 엽니다. Windows 에서는 %USERPROFILE%\.codex 폴더에 있습니다. 파일이 없으면 새로 만듭니다.
  3. 파일 끝에 붙여넣고 저장합니다. 이미 [mcp_servers.mdstudio] 부분이 있으면 그 부분을 지우고 붙여넣습니다.
  4. 터미널에서 codex mcp list 를 실행해 목록에 mdstudio 가 있는지 확인합니다.

Gemini CLI

  1. 「Gemini CLI」 줄의 [복사] 버튼을 클릭합니다. "mcpServers" 가 든 설정이 복사됩니다.
  2. Gemini CLI 의 설정 파일 settings.json 을 엽니다. 사용자 폴더(%USERPROFILE%)의 .gemini 폴더에 있습니다.
  3. 파일이 비어 있으면 복사한 글을 그대로 붙여넣습니다. 이미 "mcpServers" 가 있으면 그 안에 "mdstudio" 항목만 넣습니다.
  4. 파일을 저장하고 Gemini CLI 를 시작한 뒤 /mcp 를 입력해 mdstudio 가 있는지 확인합니다.

복사한 설정에는 Gemini CLI 가 도구를 쓰기 전에 묻는 확인을 건너뛰는 trust 를 넣지 않았습니다.

마지막으로 [확인] 버튼을 클릭해 설정 창을 닫습니다.

막히면: 에이전트가 MCP server is not reachable 오류를 전하면 MDStudio 가 켜져 있고 「MCP 서버 켜기」가 선택돼 있는지 확인합니다. 포트를 바꿨다면 [복사] 버튼으로 다시 복사해 붙여넣습니다. Gemini CLI 에서 폴더 신뢰 기능을 켰다면 신뢰하지 않은 폴더에서는 MCP 서버에 연결하지 않으므로, Gemini CLI 를 시작한 폴더를 신뢰합니다. → AI 에이전트 연결(MCP)

3단계: 연결 확인하기

MDStudio 를 켜 둔 채 에이전트에 아래 요청을 입력합니다.

요청 에이전트가 보통 쓰는 도구 MDStudio 에서 보이는 것
MDStudio 에 열린 문서 목록을 보여 줘 list_documents 묻지 않습니다. 에이전트가 주간 보고.md 를 알려 줍니다

이렇게 보입니다: 아래 도구 창의 「메시지」 탭에 에이전트의 요청이 한 줄씩 남습니다.

4단계: 예제 요청 해 보기

주간 보고.md 탭을 연 채 위에서부터 차례대로 입력합니다. 어떤 도구를 쓸지는 에이전트가 정하므로 표와 다를 수 있습니다.

요청 에이전트가 보통 쓰는 도구 MDStudio 에서 보이는 것
MDStudio 에 열린 주간 보고를 요약하고 목차를 알려 줘 read_document → get_outline 묻지 않습니다. 문서는 그대로입니다
(이번 주 한 일 아래 문단을 끌어 선택한 뒤) 선택한 문단을 한 문장으로 짧게 다듬어 줘 get_selection → edit_document 확인 창에 바뀔 내용이 나옵니다. 허락하면 그 문단이 바뀝니다
실적 표의 세로선이 맞게 정리해 줘 read_document → table 확인 창이 뜹니다. 허락하면 표의 칸 너비가 맞춰집니다
문서의 문제를 찾아서 고칠 수 있는 것은 고쳐 줘 get_problems → auto_fix 확인 창이 뜹니다. 허락하면 ##다음 주 계획 이 ## 다음 주 계획 으로 바뀝니다
할 일 목록 세 줄의 맨 앞 두 칸을 열 블록으로 선택해 줘 read_document → select 묻지 않습니다. 세 줄의 - 가 사각형으로 선택됩니다
참고 메모 절을 문서 끝까지 지워 줘 read_document → delete_range 확인 창에 지울 텍스트가 나옵니다. 허락하면 그 줄들이 지워집니다
이 문서를 같은 폴더에 PDF 로 내보내 줘 get_context → export 확인 창이 뜹니다. 허락하면 연습 폴더에 주간 보고.pdf 가 생깁니다

이렇게 보입니다: 확인 창의 제목은 「AI 에이전트의 문서 변경」입니다. 처음 초점은 [취소] 버튼에 있어 Enter 로는 허락되지 않습니다.

막히면: 고치는 요청에 에이전트가 도구가 없다고 답하면 1단계의 「쓰기 도구 허용」이 선택돼 있는지 확인합니다. 확인 창은 2분 안에 답하지 않으면 거절됩니다.

5단계: 견적서 템플릿으로 새 문서 만들기

먼저 견적서.md 를 내 템플릿으로 만듭니다. {{고객}} 같은 사용자 정의 토큰은 에이전트가 값을 채웁니다.

  1. 파일 > 열기(Ctrl+O)를 클릭하고 연습 폴더의 양식\견적서.md 를 엽니다.
  2. Ctrl+A 를 눌러 모두 선택하고 Ctrl+C 를 눌러 복사합니다.
  3. 파일 > 템플릿으로 새 문서(Ctrl+Shift+N)를 클릭합니다.
  4. 「새 템플릿」 버튼을 클릭하고 이름에 견적서 를 입력한 뒤 [확인] 버튼을 클릭합니다.
  5. 「편집기에서 열어 편집」 버튼을 클릭합니다.
  6. Ctrl+A 를 누르고 Ctrl+V 를 눌러 붙여넣습니다.
  7. 파일 > 저장(Ctrl+S)을 클릭합니다.

이제 에이전트에 요청합니다.

요청 에이전트가 보통 쓰는 도구 MDStudio 에서 보이는 것
견적서 템플릿으로 한빛상사 견적서를 만들어 줘. 품목은 문서 편집 교육, 수량은 1회, 금액은 300,000원이야 list_library → new_from_template 확인 창이 뜹니다. 허락하면 새 탭에 오늘 날짜와 한빛상사·품목·금액이 채워진 견적서가 열립니다

막히면: 「편집기에서 열어 편집」 버튼이 흐리면 목록에서 견적서 를 클릭해 선택합니다. 작성자·소속·이메일 같은 기본 토큰은 에이전트가 채우지 못합니다. → 템플릿과 스니펫

안전하게 쓰기

  • 확인 창의 도구 이름과 내용이 부탁한 일과 다르면 [취소] 버튼을 클릭합니다.
  • 고친 결과가 마음에 들지 않으면 MDStudio 에서 Ctrl+Z 를 누릅니다. 에이전트의 고치기 한 번이 실행 취소 한 번입니다.
  • 「AI 앱에 사용자 정보(이름·소속·이메일) 제공」은 선택하지 않으면 에이전트가 이름·이메일을 받지 못합니다.
  • 설정 창의 「토큰」은 남에게 보여 주거나 보내지 않습니다. 새어 나갔다고 생각되면 [새로 만들기] 버튼으로 바꿉니다.
  • 에이전트를 쓰지 않을 때는 1단계의 「MCP 서버 켜기」를 해제합니다.

다 했습니다

  • 에이전트가 고친 문서는 저장하지 않은 상태입니다. 저장하려면 Ctrl+S 를 누릅니다.
  • 도구 전체 목록과 확인 규칙은 AI 에이전트 연결(MCP)을 봅니다.
